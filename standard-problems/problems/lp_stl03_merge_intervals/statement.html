Painted Road

เทศบาลจ้างทีมทาสีเส้นจราจรบนถนนเส้นตรงยาวเส้นหนึ่ง ทีมทาสีทำงานไปทั้งหมด $N$ รอบ รอบที่ $i$ ทาสีทับช่วงตั้งแต่ระยะ $l_i$ ถึง $r_i$ (หน่วยเป็นเมตร วัดจากต้นถนน) แต่ละรอบอาจทาทับช่วงที่เคยทาไปแล้วก็ได้ และรอบต่าง ๆ ไม่ได้มาเรียงกันตามตำแหน่ง

หลังทาครบทุกรอบ ส่วนที่ถูกทาสีจะกลายเป็นแถบสีที่ต่อเนื่องกันหลายแถบ ช่วงสองช่วงอยู่ในแถบเดียวกันถ้ามันมีจุดร่วมกันอย่างน้อยหนึ่งจุด แตะกันแค่จุดเดียวก็นับว่าต่อกัน เช่น $[1, 3]$ กับ $[3, 5]$ รวมเป็นแถบ $[1, 5]$ แต่ $[1, 2]$ กับ $[3, 4]$ เป็นคนละแถบ เพราะช่วงระหว่าง $2$ ถึง $3$ ไม่มีสี

จงหาจำนวนแถบสี และความยาวรวมของถนนที่ถูกทาสี (ส่วนที่ทาซ้ำนับครั้งเดียว)

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $l_i$ และ $r_i$

Output :

บรรทัดแรก : แสดงจำนวนแถบสี
บรรทัดที่สอง : แสดงความยาวรวมของถนนที่ถูกทาสี

คำอธิบายตัวอย่างที่ 1

ช่วง $[2, 6]$, $[1, 3]$ และ $[6, 8]$ ต่อกันเป็นแถบ $[1, 8]$ ยาว $7$ เมตร ช่วง $[10, 12]$ อยู่ตัวเดียวยาว $2$ เมตร ส่วน $[20, 30]$ ครอบ $[21, 25]$ ไว้ทั้งช่วงจึงเป็นแถบเดียวยาว $10$ เมตร รวมเป็น $3$ แถบ ยาว $7 + 2 + 10 = 19$ เมตร

Constraints :

  • $1 \leq N \leq 50{,}000$
  • $0 \leq l_i < r_i \leq 10^9$
