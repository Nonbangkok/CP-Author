Nearest Value

ร้านขนมของพี่นนท์มีขนมวางขายอยู่ $N$ ชิ้น ชิ้นที่ $i$ ราคา $a_i$ บาท วันนี้มีลูกค้ามาทั้งหมด $Q$ คน ลูกค้าแต่ละคนบอกแค่ว่า "อยากได้ขนมราคาประมาณ $x$ บาท" พี่นนท์จึงต้องหยิบขนมชิ้นที่ราคาใกล้ $x$ ที่สุดให้ ลูกค้าต่อแถวยาวมาก ถ้าเดินดูขนมทีละชิ้นทุกครั้งคงไม่ทันแน่ ๆ

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และคำถาม $Q$ ข้อ คำถามที่ $j$ ประกอบด้วยจำนวนเต็ม $x_j$ จงหาค่า $a_i$ ที่ทำให้ $|a_i - x_j|$ น้อยที่สุด ถ้ามีสองค่าที่ห่างจาก $x_j$ เท่ากัน ให้ตอบค่าที่น้อยกว่า

ราคาอาจซ้ำกันได้ อาจติดลบได้ (ถือว่าเป็นคูปองส่วนลด) และลำดับที่ให้มายังไม่ได้เรียง ขนมไม่หมดร้าน ลูกค้าคนก่อนหยิบไปแล้วคนถัดไปก็ยังเลือกชิ้นเดิมได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $x_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงค่า $a_i$ ที่ใกล้ $x_j$ ที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

เมื่อเรียงแล้วราคาคือ $2, 5, 9, 14$ ลูกค้าคนแรกอยากได้ราคา $6$ ซึ่งห่างจาก $5$ อยู่ $1$ และห่างจาก $9$ อยู่ $3$ จึงตอบ $5$ ลูกค้าคนที่สองอยากได้ราคา $7$ ซึ่งห่างจาก $5$ และ $9$ เท่ากันคือ $2$ จึงตอบค่าที่น้อยกว่าคือ $5$ ลูกค้าคนที่สามอยากได้ $100$ ซึ่งแพงกว่าทุกชิ้น ชิ้นที่ใกล้ที่สุดคือ $14$ และคนสุดท้ายอยากได้ $-3$ ชิ้นที่ใกล้ที่สุดคือ $2$

Constraints :

  • $1 \leq N, Q \leq 40{,}000$
  • $-10^9 \leq a_i \leq 10^9$
  • $-10^9 \leq x_j \leq 10^9$
