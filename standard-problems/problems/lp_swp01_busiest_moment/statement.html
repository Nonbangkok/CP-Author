Busiest Moment

งานเลี้ยงรุ่นของพี่นนท์จัดในห้องโถงขนาดเล็ก เจ้าหน้าที่ดับเพลิงขอข้อมูลว่าจำนวนแขกที่อยู่ในห้องพร้อมกันมากที่สุดคือกี่คน และเกิดขึ้นครั้งแรกเมื่อไร พี่นนท์มีบันทึกจากประตูทางเข้าว่ามีแขกทั้งหมด $N$ คน แขกคนที่ $i$ เดินเข้าห้องตอนเวลา $a_i$ และเดินออกตอนเวลา $b_i$ (หน่วยเป็นวินาทีนับจากเปิดงาน)

แขกคนที่ $i$ อยู่ในห้องที่ทุกเวลา $t$ ซึ่ง $a_i \leq t < b_i$ นั่นคือตอนเวลา $b_i$ พอดี แขกคนนั้นออกไปแล้ว ถ้ามีคนหนึ่งออกตอนเวลา $t$ และอีกคนเข้าตอนเวลา $t$ พอดี ทั้งสองคนไม่นับว่าอยู่ในห้องพร้อมกันที่เวลา $t$

จงหาจำนวนแขกที่มากที่สุดที่อยู่ในห้องพร้อมกัน ณ เวลาใดเวลาหนึ่ง และเวลาแรกสุด $t$ ที่ในห้องมีแขกจำนวนเท่านั้น

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $a_i$ และ $b_i$ คือเวลาเข้าและเวลาออกของแขกคนที่ $i$ (แขกไม่ได้เรียงตามเวลา)

Output :

มีบรรทัดเดียว แสดงจำนวนเต็มสองจำนวน คือจำนวนแขกที่มากที่สุดที่อยู่ในห้องพร้อมกัน และเวลาแรกสุดที่เกิดขึ้น

{{examples}}

คำอธิบายตัวอย่างที่ 1

ที่เวลา $3$ แขกคนที่ $1$, $2$ และ $5$ อยู่ในห้อง รวม $3$ คน ที่เวลา $4$ แขกคนที่ $1$ และ $5$ ออกไปแล้วพอดี เหลือคนที่ $2$ กับคนที่ $3$ ที่เพิ่งเข้ามา รวม $2$ คน ไม่มีเวลาไหนที่มีถึง $4$ คน (ถ้านับคนที่ออกตอนเวลา $4$ ว่ายังอยู่ จะได้ $4$ คนซึ่งผิด)

คำอธิบายตัวอย่างที่ 2

ที่เวลา $10$ แขกคนที่ $1$ ออกไปพอดี และคนที่ $2$ กับ $3$ เข้ามา จึงมี $2$ คน ที่เวลา $15$ คนที่ $3$ ออกและคนที่ $4$ เข้า ก็มี $2$ คนเหมือนกัน เวลาแรกสุดที่มี $2$ คนคือ $10$

Constraints :

  • $1 \leq N \leq 10^5$
  • $0 \leq a_i < b_i \leq 10^9$
