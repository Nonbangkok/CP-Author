The K-th Move of Hanoi

ณ วัดแห่งหนึ่ง มีเสาอยู่สามต้น หมายเลข $1$, $2$ และ $3$ ที่เสาต้นที่ $1$ มีจานซ้อนกันอยู่ $N$ ใบ จานใบที่ $1$ เล็กที่สุด จานใบที่ $N$ ใหญ่ที่สุด และวางเรียงจากใหญ่ (ล่างสุด) ไปเล็ก (บนสุด) พระในวัดต้องย้ายจานทั้งหมดไปไว้ที่เสาต้นที่ $3$ โดยย้ายได้ทีละใบ หยิบได้เฉพาะจานบนสุดของเสา และห้ามวางจานใหญ่ทับจานเล็ก

พระใช้วิธีย้ายแบบเดียวกันทุกครั้ง เขียนเป็นขั้นตอน $\mathrm{move}(n, x, y, z)$ ซึ่งหมายถึง "ย้ายจานใบที่ $1$ ถึง $n$ จากเสา $x$ ไปเสา $y$ โดยใช้เสา $z$ พัก" ดังนี้

  • ถ้า $n = 0$ ไม่ต้องทำอะไร
  • ไม่เช่นนั้น ทำ $\mathrm{move}(n - 1, x, z, y)$ จากนั้นย้ายจานใบที่ $n$ จากเสา $x$ ไปเสา $y$ แล้วทำ $\mathrm{move}(n - 1, z, y, x)$

พระเริ่มจาก $\mathrm{move}(N, 1, 3, 2)$ ซึ่งใช้การย้ายทั้งหมด $2^N - 1$ ครั้ง น้องนนท์มีคำถาม $Q$ ข้อ แต่ละข้อถามว่าการย้ายครั้งที่ $K$ (นับครั้งแรกเป็นครั้งที่ $1$) ย้ายจานใบไหน จากเสาไหนไปเสาไหน ปัญหาคือเมื่อ $N = 60$ ต่อให้ย้ายวินาทีละล้านครั้งก็ยังต้องใช้เวลาหลายหมื่นปี จะนั่งไล่ทีละครั้งไม่ไหวแน่ ๆ

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $K_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงจำนวนเต็มสามจำนวน คือหมายเลขจาน เสาต้นทาง และเสาปลายทาง ของการย้ายครั้งที่ $K_j$

คำอธิบายตัวอย่างที่ 1

เมื่อ $N = 3$ การย้ายทั้ง $7$ ครั้งตามลำดับคือ จาน $1$ จาก $1$ ไป $3$, จาน $2$ จาก $1$ ไป $2$, จาน $1$ จาก $3$ ไป $2$, จาน $3$ จาก $1$ ไป $3$, จาน $1$ จาก $2$ ไป $1$, จาน $2$ จาก $2$ ไป $3$ และจาน $1$ จาก $1$ ไป $3$ คำถามถามถึงการย้ายครั้งที่ $1$, $4$, $6$ และ $7$

Constraints :

  • $1 \leq N \leq 60$
  • $1 \leq Q \leq 1{,}000$
  • $1 \leq K_j \leq 2^N - 1$
