Wallpaper Strip

โรงงานพิมพ์ลายวอลเปเปอร์ด้วยการเอาแม่พิมพ์คำ $w$ หนึ่งคำมาพิมพ์ซ้ำต่อกันไปเรื่อย ๆ เป็น $www\ldots$ ไม่มีที่สิ้นสุด แล้วตัดเป็นแถบ น้องนนท์เจอแถบวอลเปเปอร์ที่เขียนเป็นสตริง $s$ ยาว $N$ ตัวอักษร แต่ไม่รู้ว่าโดนตัดมาจากตรงไหนของม้วน และส่วนท้ายของแถบอาจขาดหายไปแล้วด้วย เขาจึงถาม $Q$ ครั้ง ครั้งละหนึ่งความยาว $L$ ว่าถ้าแถบจริงคือ $L$ ตัวแรกของ $s$ (เรียกว่า $u = s_1 s_2 \ldots s_L$) แล้ว

  1. แม่พิมพ์ $w$ ที่สั้นที่สุดที่ทำให้ $u$ เป็นสตริงย่อยที่ติดกันของ $www\ldots$ ได้ ยาวเท่าไร เรียกความยาวนี้ว่า $p$ (เท่ากับค่า $p \geq 1$ ที่น้อยที่สุดซึ่ง $u_i = u_{i+p}$ สำหรับทุก $1 \leq i \leq L - p$)
  2. ถ้าจะเขียน $u$ เป็นคำเดียวกันต่อกันพอดี $c$ ครั้ง คือ $u = vv\ldots v$ ($c$ ชุด ไม่มีเศษ) ค่า $c$ ที่มากที่สุดที่เป็นไปได้คือเท่าไร (ทุกสตริงเขียนเป็นตัวเองหนึ่งชุดได้เสมอ จึงได้ $c \geq 1$)

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับสตริง $s$ ยาว $N$ ตัวอักษร ประกอบด้วยตัวอักษรภาษาอังกฤษพิมพ์เล็กเท่านั้น
บรรทัดที่สาม : รับจำนวนเต็ม $Q$ จำนวน คือความยาว $L$ ของแต่ละคำถาม

Output :

มีทั้งหมด $Q$ บรรทัด โดยบรรทัดที่ $j$ แสดงจำนวนเต็มสองจำนวน $p$ และ $c$ ของคำถามที่ $j$ คั่นด้วยช่องว่าง

{{examples}}

คำอธิบายตัวอย่างที่ 1

$L = 6$ : abcabc ใช้แม่พิมพ์ abc ยาว $3$ และเป็น abc สองชุดพอดี ตอบ $3$ $2$   $L = 9$ : abcabcabc ตอบ $3$ $3$   $L = 11$ : abcabcabcab ยังใช้แม่พิมพ์ยาว $3$ ได้ (ส่วนท้ายขาดไป) แต่แบ่งเป็นชุดเท่า ๆ กันไม่ได้ ตอบ $3$ $1$   $L = 4$ : abca ตอบ $3$ $1$   $L = 2$ : ab แม่พิมพ์ที่สั้นที่สุดคือ ab เอง ตอบ $2$ $1$

คำอธิบายตัวอย่างที่ 2

aabaaba เป็นส่วนหนึ่งของ aab ที่พิมพ์ซ้ำ จึงได้ $p = 3$ แต่ $7$ ตัวแบ่งเป็นชุดเท่า ๆ กันไม่ได้ ตอบ $3$ $1$ ส่วน aabaab คือ aab สองชุดพอดี ตอบ $3$ $2$ และ aa ตอบ $1$ $2$

Constraints :

  • $1 \leq N \leq 2 \times 10^5$
  • $1 \leq Q \leq 2 \times 10^4$
  • $1 \leq L \leq N$ ในทุกคำถาม
  • $s$ มีแต่ตัวอักษร a ถึง z
