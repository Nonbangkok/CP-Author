Best Window

ร้านน้ำปั่นของน้องนนท์เปิดมาแล้ว $N$ วัน วันที่ $i$ ได้กำไร $a_i$ บาท บางวันฝนตกขายไม่ออกจนขาดทุน กำไรก็เลยติดลบได้ ตอนนี้น้องนนท์จะเอาผลงานไปอวดเพื่อน และเพื่อนตั้งกติกาว่าต้องเลือกช่วง $K$ วันติดกันพอดี น้องนนท์จึงอยากรู้ว่าช่วง $K$ วันติดกันที่ได้กำไรรวมมากที่สุดได้กำไรเท่าไร

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และจำนวนเต็ม $K$ จงหาค่ามากที่สุดของ $a_i + a_{i+1} + \cdots + a_{i+K-1}$ เมื่อ $1 \leq i \leq N - K + 1$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $K$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงกำไรรวมที่มากที่สุดของช่วง $K$ วันติดกัน (อาจติดลบได้)

{{examples}}

คำอธิบายตัวอย่างที่ 1

ช่วง $3$ วันติดกันมีทั้งหมด $4$ ช่วง ได้ผลรวม $1 + (-2) + 4 = 3$, $(-2) + 4 + 5 = 7$, $4 + 5 + (-1) = 8$ และ $5 + (-1) + 2 = 6$ ช่วงที่ดีที่สุดได้ $8$

คำอธิบายตัวอย่างที่ 2

ทุกวันขาดทุนหมด ช่วง $2$ วันที่เสียน้อยที่สุดคือ $(-3) + (-1) = -4$

Constraints :

  • $1 \leq K \leq N \leq 10^5$
  • $-10^9 \leq a_i \leq 10^9$
