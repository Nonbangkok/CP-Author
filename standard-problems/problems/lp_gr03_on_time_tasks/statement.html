On-Time Tasks

สัปดาห์สอบของน้องนนท์มาถึงแล้ว อาจารย์สั่งงานไว้ $N$ ชิ้น งานที่ $i$ ต้องใช้เวลาทำต่อเนื่อง $t_i$ ชั่วโมง และมีกำหนดส่งภายในชั่วโมงที่ $d_i$ น้องนนท์เริ่มทำงานได้ตั้งแต่ชั่วโมงที่ $0$ ทำได้ทีละชิ้น และเมื่อเริ่มชิ้นไหนแล้วต้องทำชิ้นนั้นจนเสร็จก่อนเริ่มชิ้นถัดไป

น้องนนท์จะเลือกงานบางส่วนมาทำ และเรียงลำดับงานที่เลือกได้ตามใจ โดยทุกงานที่เลือกต้องเสร็จไม่เกินกำหนดส่ง (งานที่ $i$ ต้องเสร็จภายในชั่วโมงที่ $d_i$ พอดีหรือก่อนนั้น) งานที่ไม่ได้เลือกถือว่าทิ้งไป จงหาจำนวนงานที่มากที่สุดที่ส่งทันได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
อีก $N$ บรรทัด : บรรทัดที่ $i$ รับจำนวนเต็ม $t_i$ และ $d_i$

Output :

มีบรรทัดเดียว แสดงจำนวนงานที่มากที่สุดที่ส่งทัน

{{examples}}

คำอธิบายตัวอย่างที่ 1

ทำงานที่ $1$ เสร็จชั่วโมงที่ $100$ ต่อด้วยงานที่ $2$ เสร็จชั่วโมงที่ $300$ แล้วงานที่ $4$ เสร็จชั่วโมงที่ $2300$ ทันทั้งสามงาน ส่วนงานที่ $3$ ใช้เวลา $1000$ ชั่วโมง ถ้าใส่เพิ่มเข้าไปจะมีงานที่ไม่ทันเสมอ จึงตอบ $3$

คำอธิบายตัวอย่างที่ 2

ถ้าทำงานที่ $1$ ก่อนเพราะกำหนดส่งเร็วที่สุด จะเสร็จชั่วโมงที่ $5$ แล้วงานอื่นก็ไม่ทันอีกเลย แต่ถ้าทิ้งงานที่ $1$ แล้วทำงานที่ $2$ กับ $3$ จะเสร็จชั่วโมงที่ $2$ และ $4$ ทันทั้งคู่ จึงตอบ $2$

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq t_i \leq 10^9$
  • $1 \leq d_i \leq 10^9$
