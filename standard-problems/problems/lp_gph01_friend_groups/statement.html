Friend Groups

ปีนี้โรงเรียนจัดค่ายเข้าป่า มีนักเรียนมาร่วม $N$ คน ใส่หมายเลขประจำตัว $1$ ถึง $N$ ครูอยากจัดเต็นท์ให้ "แก๊ง" เดียวกันได้นอนใกล้กัน จึงให้ทุกคนเขียนชื่อเพื่อนสนิทส่งมา ได้คู่เพื่อนทั้งหมด $M$ คู่ ความเป็นเพื่อนนั้นส่งต่อกันได้ ถ้า A เป็นเพื่อนกับ B และ B เป็นเพื่อนกับ C แล้ว A, B, C ถือว่าอยู่กลุ่มเดียวกัน แม้ A กับ C จะไม่รู้จักกันเลยก็ตาม คนที่ไม่มีเพื่อนในรายชื่อเลยก็เป็นกลุ่มของตัวเองคนเดียว

พูดให้ชัดคือ ให้กราฟไม่มีทิศทางที่มีจุดยอด $N$ จุด และเส้นเชื่อม $M$ เส้น จงหาจำนวนกลุ่มทั้งหมด (จำนวน connected component) และจำนวนคนในกลุ่มเพื่อนที่ใหญ่ที่สุด

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $M$
อีก $M$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $u_i$ และ $v_i$ แปลว่านักเรียนหมายเลข $u_i$ กับ $v_i$ เป็นเพื่อนกัน

Output :

มีบรรทัดเดียว แสดงจำนวนเต็มสองจำนวนคั่นด้วยช่องว่าง คือจำนวนกลุ่มทั้งหมด และจำนวนคนในกลุ่มที่ใหญ่ที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

กลุ่มแรกคือ $\{1, 2, 3\}$ กลุ่มที่สองคือ $\{4, 5, 6, 7\}$ (คน $7$ เป็นเพื่อนกับ $6$ และ $6$ เป็นเพื่อนกับ $4$ ซึ่งเป็นเพื่อนกับ $5$) ส่วนคน $8$ อยู่คนเดียว จึงมี $3$ กลุ่ม และกลุ่มที่ใหญ่ที่สุดมี $4$ คน

คำอธิบายตัวอย่างที่ 2

ไม่มีคู่เพื่อนเลย ทุกคนเป็นกลุ่มของตัวเอง ได้ $4$ กลุ่ม กลุ่มละ $1$ คน

Constraints :

  • $1 \leq N \leq 10^5$
  • $0 \leq M \leq 10^5$
  • $1 \leq u_i, v_i \leq N$ และ $u_i \neq v_i$
  • ไม่มีคู่เพื่อนคู่ใดถูกเขียนซ้ำ
