Geometric Sum

น้องนนท์ตั้งใจหยอดกระปุกออมสินแบบทวีคูณ วันที่ $0$ หยอด $1$ บาท แล้วทุกวันถัดไปหยอดเป็น $a$ เท่าของเมื่อวาน วันที่ $i$ จึงหยอด $a^i$ บาท ตอนนี้เขาอยากรู้ว่าถ้าหยอดไปจนถึงวันที่ $n$ เงินในกระปุกออมสินจะมีทั้งหมดเท่าไร แต่ตัวเลขใหญ่มากจนจดไม่ไหว เลยขอแค่เศษจากการหารด้วย $m$ ก็พอ

มีคำถามทั้งหมด $Q$ ข้อ คำถามที่ $j$ ประกอบด้วยจำนวนเต็ม $a_j$, $n_j$ และ $m_j$ จงหาค่าของ

$$S_j = \left(1 + a_j + a_j^2 + \cdots + a_j^{\,n_j}\right) \bmod m_j$$

ผลรวมนี้มีทั้งหมด $n_j + 1$ พจน์ (ตั้งแต่ $a_j^0$ ถึง $a_j^{\,n_j}$) โดยกำหนดให้ $a^0 = 1$ เสมอ รวมถึง $0^0 = 1$ ด้วย

ข้อควรระวัง: $m_j$ ไม่จำเป็นต้องเป็นจำนวนเฉพาะ และ $a_j - 1$ อาจหารด้วย $m_j$ ลงตัวก็ได้ ดังนั้นสูตรที่ต้องหารด้วย $a_j - 1$ อาจใช้ไม่ได้ตรง ๆ

Input :

บรรทัดแรก : รับจำนวนเต็ม $Q$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $a_j$, $n_j$ และ $m_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงค่าของ $S_j$

{{examples}}

คำอธิบายตัวอย่างที่ 1

คำถามแรก $1 + 2 + 4 + 8 = 15$ และ $15 \bmod 100 = 15$ คำถามที่สอง $1 + 3 + 9 + 27 + 81 = 121$ และ $121 \bmod 10 = 1$ คำถามที่สามมีพจน์เดียวคือ $5^0 = 1$ คำถามที่สี่ $a = 1$ ทุกพจน์จึงเป็น $1$ ได้ผลรวม $11 \bmod 6 = 5$ ส่วนคำถามสุดท้าย $0^0 = 1$ และพจน์ที่เหลือเป็น $0$ หมด จึงได้ $1$

Constraints :

  • $1 \leq Q \leq 10^4$
  • $0 \leq a_j \leq 10^9$
  • $0 \leq n_j \leq 10^{18}$
  • $1 \leq m_j \leq 10^9$
