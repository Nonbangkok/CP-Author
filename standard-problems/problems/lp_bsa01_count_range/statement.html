Count in Range

น้องนนท์มีลำดับของจำนวนเต็มอยู่ $N$ จำนวน และมีคำถามอีก $Q$ ข้อ แต่ละคำถามอยากรู้ว่าในลำดับนี้มีกี่จำนวนที่มีค่าอยู่ระหว่าง $l$ ถึง $r$ คำถามเยอะมากจนไล่นับทีละตัวทุกรอบไม่ทันแน่ ๆ ช่วยน้องนนท์ตอบให้ทันหน่อย

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และคำถาม $Q$ ข้อ คำถามที่ $j$ ประกอบด้วยจำนวนเต็ม $l_j$ และ $r_j$ โดย $l_j \leq r_j$ จงนับจำนวนสมาชิกที่มีค่าอยู่ในช่วง $[l_j, r_j]$ (รวมปลายทั้งสองข้าง) นั่นคือจำนวนดัชนี $i$ ที่ $l_j \leq a_i \leq r_j$

สมาชิกในลำดับอาจมีค่าซ้ำกันได้ และลำดับที่ให้มายังไม่ได้เรียง

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $l_j$ และ $r_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงคำตอบของคำถามที่ $j$

{{examples}}

คำอธิบายตัวอย่างที่ 1

คำถามแรกถามช่วง $[3, 7]$ สมาชิกที่อยู่ในช่วงคือ $5, 3, 7, 3$ จึงตอบ $4$ คำถามที่สองไม่มีสมาชิกตัวไหนอยู่ในช่วง $[10, 20]$ เลย ส่วนคำถามที่สามมีแค่ $1$ ที่อยู่ในช่วง $[-5, 1]$

Constraints :

  • $1 \leq N, Q \leq 40{,}000$
  • $-10^6 \leq a_i \leq 10^6$
  • $-10^6 \leq l_j \leq r_j \leq 10^6$
