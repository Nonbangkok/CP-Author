# Count in Range

น้องนนท์มีลำดับของจำนวนเต็ม $N$ จำนวน และมีคำถามอีก $Q$ ข้อ แต่ละคำถามอยากรู้ว่า
ในลำดับนี้มีกี่จำนวนที่มีค่าอยู่ระหว่าง $l$ ถึง $r$ คำถามเยอะมากจนไล่นับทีละตัวทุกรอบ
ไม่ทันแน่ ๆ ช่วยน้องนนท์ตอบให้ทันหน่อย

## คำอธิบาย :

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และคำถาม $Q$ ข้อ คำถามที่ $j$ ประกอบด้วยจำนวนเต็ม
$l_j$ และ $r_j$ โดย $l_j \leq r_j$ ให้<b>นับจำนวนสมาชิกที่มีค่าอยู่ในช่วง</b>
$[l_j, r_j]$ (รวมปลายทั้งสองข้าง) นั่นคือจำนวนดัชนี $i$ ที่ $l_j \leq a_i \leq r_j$

สมาชิกในลำดับอาจมีค่าซ้ำกันได้ และลำดับที่ให้มา<b>ยังไม่ได้เรียง</b>

## Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$<br>
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$<br>
อีก $Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $l_j$ และ $r_j$

## Output :

มีทั้งหมด $Q$ บรรทัด บรรทัดที่ $j$ แสดงคำตอบของคำถามที่ $j$

## Examples :

### ตัวอย่างที่ 1

```sample-input
6 3
5 1 9 3 7 3
3 7
10 20
-5 1
```

```sample-output
4
0
1
```

## คำอธิบายตัวอย่างที่ 1

คำถามแรกถามช่วง $[3, 7]$ สมาชิกที่อยู่ในช่วงคือ $5, 3, 7, 3$ จึงตอบ $4$
คำถามที่สองไม่มีสมาชิกตัวไหนอยู่ในช่วง $[10, 20]$ เลย ส่วนคำถามที่สามมีแค่ $1$
ที่อยู่ในช่วง $[-5, 1]$

## Constraints :

* $1 \leq N, Q \leq 40{,}000$
* $-10^6 \leq a_i \leq 10^6$
* $-10^6 \leq l_j \leq r_j \leq 10^6$
