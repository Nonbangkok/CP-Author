Greenhouse Rows

โรงเรือนปลูกผักไฮโดรโปนิกส์ของพี่นนท์มีแปลงผัก $N$ แปลงเรียงกันเป็นแถว แปลงที่ $i$ มีอุณหภูมิ $a_i$ หน่วย ระบบควบคุมมีปุ่มอยู่สองแบบ แบบแรกคือเครื่องทำความร้อน/เย็น ที่ปรับอุณหภูมิทุกแปลงในช่วงให้เปลี่ยนไปเท่ากัน อีกแบบคือปุ่มรีเซ็ต ที่ตั้งอุณหภูมิทุกแปลงในช่วงให้เป็นค่าเดียวกัน ส่วนผักบางชนิดไม่ทนร้อน พี่นนท์จึงต้องคอยเช็กว่าแปลงที่ร้อนที่สุดในช่วงนั้นร้อนแค่ไหน

เริ่มต้นแปลงที่ $i$ มีอุณหภูมิ $a_i$ จากนั้นมีเหตุการณ์ $Q$ อย่างเกิดขึ้นตามลำดับ แต่ละอย่างเป็นแบบใดแบบหนึ่ง

  • 1 l r v : ทุกแปลงที่ $l \leq i \leq r$ อุณหภูมิเปลี่ยนไป $v$ หน่วย คือ $a_i$ กลายเป็น $a_i + v$ ($v$ ติดลบได้)
  • 2 l r v : ทุกแปลงที่ $l \leq i \leq r$ อุณหภูมิถูกตั้งเป็น $v$ คือ $a_i$ กลายเป็น $v$
  • 3 l r : ให้หาค่าที่มากที่สุดของ $a_l, a_{l+1}, \ldots, a_r$ ณ ขณะนั้น

อุณหภูมิในเกมนี้ติดลบได้ และอาจไกลจาก $0$ เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : แต่ละบรรทัดเป็นเหตุการณ์หนึ่งอย่าง ในรูป 1 l r v, 2 l r v หรือ 3 l r ตามลำดับที่เกิด

Output :

สำหรับเหตุการณ์แบบ 3 แต่ละครั้ง ให้แสดงอุณหภูมิที่มากที่สุดบรรทัดละหนึ่งคำตอบ ตามลำดับที่ถาม

{{examples}}

คำอธิบายตัวอย่างที่ 1

ตอนแรกอุณหภูมิคือ $20, 25, 22, 30, 18, 27$ คำถาม $[1, 3]$ ได้ $25$ จากนั้นแปลง $2$ ถึง $5$ ร้อนขึ้น $5$ เป็น $20, 30, 27, 35, 23, 27$ แล้วแปลง $3$ ถึง $6$ ถูกรีเซ็ตเป็น $10$ เป็น $20, 30, 10, 10, 10, 10$ คำถาม $[3, 6]$ จึงได้ $10$ แล้วแปลง $1$ ถึง $4$ เย็นลง $8$ เป็น $12, 22, 2, 2, 10, 10$ คำถาม $[1, 6]$ ได้ $22$ และคำถาม $[3, 5]$ ได้ $10$

คำอธิบายตัวอย่างที่ 2

รีเซ็ตทั้งแถวเป็น $-5$ แล้วเพิ่ม $3$ เฉพาะแปลงที่ $2$ จะได้ $-5, -2, -5$ คำตอบจึงเป็น $-2$ จากนั้นรีเซ็ตแปลง $2$ ถึง $3$ เป็น $-7$ แล้วลดทั้งแถวลงอีก $10^9$ ได้ $-1{,}000{,}000{,}005$, $-1{,}000{,}000{,}007$, $-1{,}000{,}000{,}007$ คำตอบจึงเป็น $-1{,}000{,}000{,}005$

Constraints :

  • $1 \leq N, Q \leq 5 \times 10^4$
  • $-10^9 \leq a_i, v \leq 10^9$
  • $1 \leq l \leq r \leq N$
  • มีเหตุการณ์แบบ 3 อย่างน้อยหนึ่งครั้ง
