Party Planning

ใกล้ถึงงานเลี้ยงวันเกิดของน้องนนท์แล้ว เขามีเพื่อนที่อยากชวนอยู่ $N$ คน เพื่อนคนที่ $i$ จะทำให้งานสนุกขึ้น $v_i$ แต้ม แต่ก็ต้องเลี้ยงขนมเพิ่มเป็นเงิน $c_i$ บาท และน้องนนท์มีงบทั้งหมดแค่ $B$ บาท

ปัญหาคือเพื่อนบางคู่ทะเลาะกันอยู่ มีทั้งหมด $M$ คู่ ถ้าชวนทั้งสองคนในคู่ที่ทะเลาะกันมาพร้อมกัน งานจะพังทันที จึงห้ามเลือกทั้งสองคนในคู่เดียวกัน

จงเลือกกลุ่มเพื่อนที่จะชวน (จะไม่ชวนใครเลยก็ได้) โดยค่าใช้จ่ายรวมไม่เกิน $B$ และไม่มีคู่ที่ทะเลาะกันอยู่ในกลุ่มพร้อมกัน แล้วตอบความสนุกรวมที่มากที่สุดที่เป็นไปได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$, $M$ และ $B$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $c_i$ และ $v_i$
$M$ บรรทัดถัดมา : แต่ละบรรทัดรับจำนวนเต็ม $x$ และ $y$ แปลว่าเพื่อนคนที่ $x$ กับคนที่ $y$ ทะเลาะกัน

Output :

มีบรรทัดเดียว แสดงความสนุกรวมที่มากที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

ถ้าเลือกเพื่อนคนที่ $1$, $2$ และ $4$ จะใช้เงิน $3 + 4 + 2 = 9$ บาท ได้ความสนุก $5 + 6 + 3 = 14$ แต้ม แต่คนที่ $1$ กับคนที่ $2$ ทะเลาะกันอยู่ จึงเลือกพร้อมกันไม่ได้ ทางที่ดีที่สุดคือเลือกคนที่ $2$, $3$ และ $4$ ใช้เงิน $4 + 3 + 2 = 9$ บาท ได้ความสนุก $6 + 4 + 3 = 13$ แต้ม

คำอธิบายตัวอย่างที่ 2

เพื่อนทุกคนแพงเกินงบ จึงชวนใครไม่ได้เลย ความสนุกรวมเป็น $0$

Constraints :

  • $1 \leq N \leq 20$
  • $0 \leq M \leq 50$
  • $0 \leq B \leq 10^{10}$
  • $1 \leq c_i, v_i \leq 10^9$
  • $1 \leq x, y \leq N$, $x \neq y$ และไม่มีคู่ใดซ้ำกัน
