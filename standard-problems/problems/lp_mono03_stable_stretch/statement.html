Stable Stretch

ห้องแล็บของพี่นนท์ติดเซนเซอร์วัดแรงดันไฟไว้ เซนเซอร์บันทึกค่าไว้ $N$ ครั้งเรียงตามเวลา ครั้งที่ $i$ อ่านได้ $a_i$ หัวหน้าแล็บอยากรู้ว่าไฟ "นิ่ง" ได้นานที่สุดแค่ไหน โดยช่วงเวลาหนึ่งจะนับว่านิ่งก็ต่อเมื่อค่าที่มากที่สุดลบค่าที่น้อยที่สุดในช่วงนั้นไม่เกิน $D$

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และจำนวนเต็ม $D$ ช่วง $[l, r]$ (โดย $1 \leq l \leq r \leq N$) เป็นช่วงนิ่งถ้า

$$\max(a_l, a_{l+1}, \ldots, a_r) - \min(a_l, a_{l+1}, \ldots, a_r) \leq D$$

จงหาความยาว $r - l + 1$ ที่มากที่สุดของช่วงนิ่ง และจุดเริ่มต้น $l$ ของช่วงนิ่งที่ยาวที่สุดนั้น ถ้ามีหลายช่วงที่ยาวที่สุดเท่ากัน ให้ตอบช่วงที่เริ่มทางซ้ายที่สุด (สังเกตว่าช่วงยาว $1$ เป็นช่วงนิ่งเสมอ)

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $D$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนเต็มสองจำนวน คือความยาวของช่วงนิ่งที่ยาวที่สุด และจุดเริ่มต้น $l$ ของช่วงนั้น (นับตำแหน่งแรกเป็น $1$)

{{examples}}

คำอธิบายตัวอย่างที่ 1

ช่วง $[5, 8]$ คือ $4, 5, 6, 3$ มีค่ามากที่สุด $6$ และน้อยที่สุด $3$ ต่างกัน $3 \leq D$ จึงเป็นช่วงนิ่งยาว $4$ ส่วนช่วง $[1, 4]$ คือ $5, 7, 6, 9$ ต่างกัน $9 - 5 = 4$ เกิน $D$ และไม่มีช่วงนิ่งยาว $5$ เลย

คำอธิบายตัวอย่างที่ 2

เมื่อ $D = 0$ ทุกค่าในช่วงต้องเท่ากัน ช่วงที่ยาวที่สุดยาว $2$ มีสองช่วงคือ $[1, 2]$ และ $[3, 4]$ จึงตอบช่วงที่เริ่มซ้ายกว่าคือ $l = 1$

Constraints :

  • $1 \leq N \leq 10^5$
  • $0 \leq D \leq 10^9$
  • $0 \leq a_i \leq 10^9$
