Budget Streaks

น้องนนท์เริ่มจดบัญชีรายจ่ายตามที่คุณแม่สั่ง ตลอด $N$ วันที่ผ่านมา วันที่ $i$ ใช้เงินไป $a_i$ บาท (บางวันไม่ได้ใช้เงินเลย ก็จดเป็น $0$) คุณแม่ตั้งเกณฑ์ไว้ว่า ช่วงวันติดกันช่วงไหนที่ใช้เงินรวมกันไม่เกิน $S$ บาท ถือว่าเป็น "ช่วงประหยัด" ได้รับคำชม น้องนนท์อยากรู้ว่าบัญชีของตัวเองมีช่วงประหยัดซ่อนอยู่ทั้งหมดกี่ช่วง

ให้ลำดับ $a_1, a_2, \ldots, a_N$ ซึ่งไม่มีค่าติดลบ และจำนวนเต็ม $S$ จงนับจำนวนคู่ $(l, r)$ ที่ $1 \leq l \leq r \leq N$ และ $a_l + a_{l+1} + \cdots + a_r \leq S$

ช่วงที่ต่างกันแค่จุดเริ่มหรือจุดจบก็นับเป็นคนละช่วง และคำตอบอาจใหญ่เกินขอบเขตของ int

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $S$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนช่วง $(l, r)$ ที่ผลรวมไม่เกิน $S$

{{examples}}

คำอธิบายตัวอย่างที่ 1

รายจ่ายคือ $2, 1, 3, 0, 4$ และ $S = 4$ ช่วงที่ใช้ได้คือช่วงที่มีวันเดียว $5$ ช่วง (ทุกค่าไม่เกิน $4$) กับ $[2, 1], [1, 3], [3, 0], [0, 4], [1, 3, 0]$ รวมทั้งหมด $10$ ช่วง

คำอธิบายตัวอย่างที่ 2

เมื่อ $S = 0$ ช่วงที่ใช้ได้ต้องเป็นวันที่ไม่ได้ใช้เงินติดกันล้วน ๆ มี $0, 0$ ติดกันอยู่ช่วงเดียว นับได้ $3$ ช่วง กับ $0$ อีกตัวที่อยู่โดด ๆ อีก $1$ ช่วง รวม $4$ ช่วง

Constraints :

  • $1 \leq N \leq 10^5$
  • $0 \leq a_i \leq 10^9$
  • $0 \leq S \leq 10^{14}$
