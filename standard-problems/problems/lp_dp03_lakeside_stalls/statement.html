Lakeside Stalls

งานวัดปีนี้จัดรอบสระน้ำ มีจุดตั้งร้าน $N$ จุดเรียงเป็นวงกลมรอบสระ จุดที่ $i$ อยู่ติดกับจุดที่ $i - 1$ และ $i + 1$ และเพราะเป็นวงกลม จุดที่ $N$ ก็อยู่ติดกับจุดที่ $1$ ด้วย ถ้าชมรมเปิดร้านที่จุดที่ $i$ จะได้กำไร $a_i$ บาท แต่คณะกรรมการไม่อยากให้คนแออัด จึงตั้งกฎว่าห้ามเปิดร้านสองจุดที่อยู่ติดกัน

ชมรมจะเลือกจุดเปิดร้านกี่จุดก็ได้ (ไม่เปิดเลยก็ได้) ตราบใดที่ไม่มีสองจุดที่เลือกอยู่ติดกัน จงหากำไรรวมที่มากที่สุดที่ทำได้

ระวังว่าคำตอบอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$ ตามลำดับรอบสระ

Output :

มีบรรทัดเดียว แสดงกำไรรวมที่มากที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

เลือกจุดที่ $1, 4$ ได้ $8 + 9 = 17$ หรือจุดที่ $2, 4, 6$ ได้ $2 + 9 + 7 = 18$ ซึ่งดีที่สุด ส่วนจุดที่ $1, 4, 6$ ได้ $24$ ก็จริง แต่จุดที่ $6$ กับจุดที่ $1$ อยู่ติดกันบนวงกลม จึงใช้ไม่ได้

คำอธิบายตัวอย่างที่ 2

จุดที่ $1$ กับจุดที่ $4$ อยู่ติดกัน จึงเลือกทั้งสองจุดไม่ได้ คำตอบคือ $10 + 1 = 11$ เช่นเลือกจุดที่ $1$ กับ $3$

Constraints :

  • $3 \leq N \leq 10^5$
  • $0 \leq a_i \leq 10^9$
