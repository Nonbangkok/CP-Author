บริษัทเอเจนซีของพี่นนท์ได้งานใหญ่ ต้องติดป้ายโฆษณารูปสี่เหลี่ยมผืนผ้าผืนเดียวลงบนผนังด้านหน้าของตึกแถวริมถนน ตึกแถวมี $N$ ตึกเรียงติดกันจากซ้ายไปขวา ทุกตึกตั้งอยู่บนพื้นเดียวกัน ตึกที่ $i$ กว้าง $w_i$ เมตรและสูง $h_i$ เมตร ไม่มีช่องว่างระหว่างตึก

มองจากหน้าตึก ผนังทั้งหมดคือรูปที่ได้จากการวางสี่เหลี่ยมกว้าง $w_i$ สูง $h_i$ ต่อกันบนพื้น ป้ายต้องวางตั้งตรง (ด้านขนานกับพื้นและกับผนังตึก) และต้องอยู่บนผนังทั้งผืน ห้ามยื่นออกไปในอากาศเหนือตึกที่เตี้ยกว่า ป้ายจะคร่อมรอยต่อระหว่างตึกก็ได้ จงหาพื้นที่มากที่สุดของป้ายที่ติดได้

ระวังว่าคำตอบอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $w_i$ และ $h_i$ คือความกว้างและความสูงของตึกที่ $i$ (เรียงจากซ้ายไปขวา)

Output :

มีบรรทัดเดียว แสดงพื้นที่มากที่สุดของป้าย (หน่วยเป็นตารางเมตร)

{{examples}}

คำอธิบายตัวอย่างที่ 1

ทุกตึกกว้าง $1$ เมตร ป้ายที่ดีที่สุดสูง $5$ เมตร คร่อมตึกที่ $3$ และ $4$ (สูง $5$ และ $6$) กว้าง $2$ เมตร ได้พื้นที่ $10$ ถ้าจะให้กว้างกว่านี้ต้องคร่อมตึกที่เตี้ยลง เช่น ป้ายสูง $2$ คร่อมตึกที่ $3$ ถึง $6$ ได้แค่ $8$

คำอธิบายตัวอย่างที่ 2

ป้ายสูง $5$ คร่อมตึกที่ $2$ และ $3$ กว้าง $1 + 2 = 3$ เมตร ได้พื้นที่ $15$ ส่วนป้ายที่กว้างที่สุดคือสูง $1$ คร่อมทุกตึก กว้าง $10$ เมตร ได้แค่ $10$ และป้ายสูง $2$ คร่อมตึกที่ $1$ ถึง $3$ ได้ $2 \times 6 = 12$

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq w_i \leq 10^4$
  • $1 \leq h_i \leq 10^9$
