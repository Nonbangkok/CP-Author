Bonus Points

ครูนนท์สอนห้องที่มีนักเรียน $N$ คน เรียงตามเลขที่ $1$ ถึง $N$ ตอนต้นเทอม นักเรียนเลขที่ $i$ มีคะแนนเก็บ $a_i$ คะแนน ครูชอบแจกคะแนนเป็นกลุ่ม เช่น "เลขที่ $5$ ถึง $12$ ช่วยจัดห้อง ได้คนละ $3$ คะแนน" หรือหักคะแนนเป็นกลุ่มเมื่อมีคนคุยเสียงดัง และนักเรียนก็ชอบเดินมาถามคะแนนของตัวเองระหว่างคาบ

มีเหตุการณ์เกิดขึ้น $Q$ ครั้งตามลำดับ แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • 1 l r x : นักเรียนทุกคนที่มีเลขที่ตั้งแต่ $l$ ถึง $r$ (รวมทั้งสองคน) ได้คะแนนเพิ่มคนละ $x$ คะแนน ถ้า $x$ ติดลบแปลว่าถูกหักคะแนน
  • 2 i : นักเรียนเลขที่ $i$ มาถามคะแนนของตัวเอง ให้ตอบคะแนนปัจจุบันของนักเรียนเลขที่ $i$

คะแนนติดลบได้ (ครูดุจริง) ไม่ต้องปัดเป็น $0$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : แต่ละบรรทัดเป็นเหตุการณ์หนึ่งครั้งตามรูปแบบข้างบน

Output :

สำหรับเหตุการณ์แบบ $2$ แต่ละครั้ง ตามลำดับ ให้แสดงคะแนนปัจจุบันของนักเรียนคนนั้น บรรทัดละหนึ่งคำตอบ

{{examples}}

คำอธิบายตัวอย่างที่ 1

หลังเหตุการณ์แรก คะแนนเป็น $10, 25, 35, 45, 50$ เลขที่ $3$ จึงมี $35$ คะแนน จากนั้นเลขที่ $1$ ถึง $3$ ถูกหักคนละ $10$ คะแนน คะแนนเป็น $0, 15, 25, 45, 50$ เลขที่ $1$, $4$ และ $3$ จึงมี $0$, $45$ และ $25$ คะแนนตามลำดับ

คำอธิบายตัวอย่างที่ 2

มีนักเรียนคนเดียว ถูกหัก $10^6$ คะแนน จาก $7$ จึงเหลือ $7 - 10^6 = -999{,}993$ คะแนน

Constraints :

  • $1 \leq N, Q \leq 5 \times 10^4$
  • $0 \leq a_i \leq 10^6$
  • $1 \leq l \leq r \leq N$ และ $-10^6 \leq x \leq 10^6$
  • $1 \leq i \leq N$
  • มีเหตุการณ์แบบ $2$ อย่างน้อยหนึ่งครั้ง
