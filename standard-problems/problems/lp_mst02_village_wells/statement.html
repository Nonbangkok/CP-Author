Village Wells

หน้าแล้งปีนี้ อำเภอของพี่นนท์มีหมู่บ้าน $N$ หมู่บ้าน (หมายเลข $1$ ถึง $N$) และทุกหมู่บ้านต้องมีน้ำใช้ หมู่บ้านหนึ่งจะได้น้ำได้สองวิธี

  • ขุดบ่อในหมู่บ้านเอง หมู่บ้านที่ $i$ ขุดบ่อได้ในราคา $c_i$ บาท
  • ต่อท่อจากหมู่บ้านอื่นที่มีน้ำอยู่แล้ว มีแนวท่อที่วางได้ $M$ แนว แนวที่ $j$ เชื่อมหมู่บ้าน $u_j$ กับหมู่บ้าน $v_j$ ราคา $w_j$ บาท น้ำไหลผ่านท่อได้ทั้งสองทิศ และส่งต่อผ่านหลายหมู่บ้านได้

พูดอีกแบบคือ หลังสร้างเสร็จ ทุกหมู่บ้านต้องมีบ่อของตัวเอง หรือเดินตามท่อที่วางไว้ไปถึงหมู่บ้านที่มีบ่อได้ จงหาค่าใช้จ่ายรวมที่น้อยที่สุด (ค่าขุดบ่อรวมกับค่าวางท่อ) ระหว่างหมู่บ้านคู่เดียวกันอาจมีแนวท่อให้เลือกหลายแนว

ระวังว่าค่าใช้จ่ายรวมอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $M$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $c_1, c_2, \ldots, c_N$
อีก $M$ บรรทัด : บรรทัดที่ $j$ รับจำนวนเต็ม $u_j$, $v_j$ และ $w_j$ แทนแนวท่อระหว่างหมู่บ้าน $u_j$ กับหมู่บ้าน $v_j$ ราคา $w_j$ บาท

Output :

มีบรรทัดเดียว แสดงค่าใช้จ่ายรวมที่น้อยที่สุดที่ทำให้ทุกหมู่บ้านมีน้ำใช้

{{examples}}

คำอธิบายตัวอย่างที่ 1

ขุดบ่อที่หมู่บ้าน $2$ ($2$ บาท) แล้ววางท่อ $1 - 2$ ($1$ บาท) และ $2 - 3$ ($1$ บาท) รวม $4$ บาท ถ้าขุดบ่อทุกหมู่บ้านจะเสีย $5 + 2 + 2 = 9$ บาท ถ้าขุดบ่อที่หมู่บ้าน $2$ และ $3$ แล้ววางท่อ $1 - 2$ จะเสีย $2 + 2 + 1 = 5$ บาท ซึ่งแพงกว่า

คำอธิบายตัวอย่างที่ 2

หมู่บ้าน $1, 2, 3$ ต่อท่อถึงกันได้ ขุดบ่อที่หมู่บ้าน $3$ ($4$ บาท) แล้ววางท่อ $1 - 2$ ($2$ บาท) และ $2 - 3$ ($3$ บาท) ส่วนหมู่บ้าน $4$ ไม่มีท่อมาถึงเลย ต้องขุดบ่อเอง ($6$ บาท) หมู่บ้าน $5$ ขุดบ่อเองราคา $1$ บาทถูกกว่าวางท่อ $10$ บาท รวม $4 + 2 + 3 + 6 + 1 = 16$ บาท

Constraints :

  • $1 \leq N \leq 5 \times 10^4$
  • $0 \leq M \leq 10^5$
  • $1 \leq c_i \leq 10^6$
  • $1 \leq u_j, v_j \leq N$ และ $u_j \neq v_j$
  • $1 \leq w_j \leq 10^6$
