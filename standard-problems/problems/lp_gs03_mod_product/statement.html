Sum and Product Modulo

ชมรมคณิตศาสตร์ของน้องนนท์เล่นเกมกัน แต่ละคนเขียนจำนวนเต็มไม่ติดลบคนละหนึ่งจำนวน รวมทั้งหมด $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$ แล้วประธานชมรมก็ถามว่า ผลบวกของทุกจำนวน และผลคูณของทุกจำนวน มีค่าเท่าไร

ไม่นานทุกคนก็พบว่าตัวเลขใหญ่เกินกว่าจะเขียนลงกระดาน ประธานจึงขอแค่เศษจากการหารด้วย $10^9 + 7$ ของทั้งสองค่า

ให้ $P = 10^9 + 7$ จงหา $(a_1 + a_2 + \cdots + a_N) \bmod P$ และ $(a_1 \times a_2 \times \cdots \times a_N) \bmod P$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีทั้งหมด $2$ บรรทัด โดย
บรรทัดแรก แสดงผลบวกของทุกจำนวน หารด้วย $10^9 + 7$ แล้วเหลือเศษเท่าไร
บรรทัดที่สอง แสดงผลคูณของทุกจำนวน หารด้วย $10^9 + 7$ แล้วเหลือเศษเท่าไร

{{examples}}

คำอธิบายตัวอย่างที่ 1

ผลบวกคือ $2 + 3 + 7 = 12$ และผลคูณคือ $2 \times 3 \times 7 = 42$ ทั้งสองค่าน้อยกว่า $10^9 + 7$ จึงตอบค่าเดิมได้เลย

คำอธิบายตัวอย่างที่ 2

ผลบวกคือ $2{,}000{,}000{,}000$ หารด้วย $1{,}000{,}000{,}007$ เหลือเศษ $999{,}999{,}993$ ส่วนผลคูณคือ $10^{18}$ ซึ่งหารด้วย $10^9 + 7$ แล้วเหลือเศษ $49$

Constraints :

  • $1 \leq N \leq 100{,}000$
  • $0 \leq a_i \leq 10^{18}$
