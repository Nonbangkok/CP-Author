Deadline Jobs

ช่วงปิดเทอม พี่นนท์รับงานฟรีแลนซ์เขียนโปรแกรม มีลูกค้าเสนองานมา $N$ งาน งานที่ $i$ ให้ค่าจ้าง $p_i$ บาท และลูกค้าต้องได้งานภายในวันที่ $d_i$ ทุกงานใช้เวลาทำพอดีหนึ่งวัน และแต่ละวันทำงานได้แค่งานเดียว พี่นนท์เริ่มทำงานได้ตั้งแต่วันที่ $1$

งานที่ $i$ จะได้เงินก็ต่อเมื่อทำในวันที่ $1, 2, \ldots, d_i$ วันใดวันหนึ่ง งานที่ทำไม่ทันพี่นนท์จะปฏิเสธไปตั้งแต่แรก จงหาค่าจ้างรวมที่มากที่สุดที่พี่นนท์ได้รับ

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
อีก $N$ บรรทัด : บรรทัดที่ $i$ รับจำนวนเต็ม $d_i$ และ $p_i$

Output :

มีบรรทัดเดียว แสดงค่าจ้างรวมที่มากที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

วันที่ $1$ ทำงานที่ $3$ (ได้ $27$) วันที่ $2$ ทำงานที่ $1$ (ได้ $100$) และวันที่ $3$ ทำงานที่ $5$ (ได้ $15$) รวม $142$ งานที่ $2$ กับ $4$ ต้องทำในวันที่ $1$ เท่านั้น ถ้าเลือกทำงานใดงานหนึ่งในนั้น จะต้องสละงานที่ $3$ ซึ่งให้มากกว่า

คำอธิบายตัวอย่างที่ 2

ทำครบทั้งสี่งานได้ เช่น วันที่ $1$ ทำงานที่ $4$ วันที่ $2$ ทำงานที่ $2$ แล้ววันที่ $3$ และ $4$ ทำงานที่ $1$ และ $3$ ได้ $3{,}000{,}000{,}001$ บาท ซึ่งเกินกว่าที่ int เก็บได้

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq d_i \leq 10^9$
  • $1 \leq p_i \leq 10^9$
