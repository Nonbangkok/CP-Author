Heavy Treasures

เรือสำรวจของชมรมเจอซากเรือโบราณที่มีสมบัติ $N$ ชิ้น ชิ้นที่ $i$ หนัก $w_i$ กรัมและมีมูลค่า $v_i$ เหรียญ แต่เรือรับน้ำหนักเพิ่มได้ไม่เกิน $W$ กรัม แต่ละชิ้นจะเลือกเอาขึ้นเรือหรือไม่เอาก็ได้ (เอาชิ้นเดียวกันซ้ำไม่ได้)

จงหามูลค่ารวมที่มากที่สุดของสมบัติที่เอาขึ้นเรือได้ โดยน้ำหนักรวมต้องไม่เกิน $W$

สังเกตว่าน้ำหนักมีค่าได้ถึง $10^9$ แต่มูลค่าของแต่ละชิ้นไม่เกิน $1{,}000$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $W$
อีก $N$ บรรทัดต่อมา : บรรทัดที่ $i$ รับจำนวนเต็ม $w_i$ และ $v_i$

Output :

มีบรรทัดเดียว แสดงมูลค่ารวมที่มากที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

เลือกชิ้นที่ $1, 3, 4$ หนักรวม $400{,}000{,}000 + 500{,}000{,}000 + 100{,}000{,}000 = 10^9$ กรัมพอดี ได้มูลค่า $30 + 45 + 10 = 85$ เหรียญ ส่วนชิ้นที่ $1, 2$ ก็หนัก $10^9$ พอดีเหมือนกันแต่ได้แค่ $80$ เหรียญ

คำอธิบายตัวอย่างที่ 2

ชิ้นแรกหนักเกิน $W$ จึงเอาได้แค่ชิ้นที่สอง ได้ $1$ เหรียญ

Constraints :

  • $1 \leq N \leq 100$
  • $1 \leq W \leq 10^9$
  • $1 \leq w_i \leq 10^9$
  • $1 \leq v_i \leq 1{,}000$
