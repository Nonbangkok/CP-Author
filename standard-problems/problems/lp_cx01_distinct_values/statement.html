Distinct Values

น้องนนท์สะสมสติกเกอร์ ทุกแผ่นมีหมายเลขกำกับไว้ ตอนนี้มีอยู่ $N$ แผ่น ซึ่งบางแผ่นก็ได้มาซ้ำกัน น้องนนท์อยากรู้ว่าตัวเองมีสติกเกอร์ที่ไม่ซ้ำกันเลยกี่แบบ นั่นคือในหมายเลขทั้ง $N$ จำนวน มีค่าที่แตกต่างกันทั้งหมดกี่ค่า

ให้ลำดับ $a_1, a_2, \ldots, a_N$ จงหาจำนวนค่าที่แตกต่างกันในลำดับนี้ คอลเลกชันของน้องนนท์ใหญ่มาก จึงต้องคิดให้เร็วกว่าการจับคู่เทียบทุกคู่

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนค่าที่แตกต่างกันในลำดับ

{{examples}}

คำอธิบายตัวอย่างที่ 1

ค่าที่ปรากฏคือ $3, 1, 4, 5, 9, 2, 6$ รวม $7$ ค่า ($1$ และ $5$ ปรากฏสองครั้ง แต่นับครั้งเดียว)

Constraints :

  • $1 \leq N \leq 100{,}000$
  • $-10^9 \leq a_i \leq 10^9$
