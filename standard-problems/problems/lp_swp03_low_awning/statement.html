Low Awning

ตลาดนัดริมถนนมีร้านค้ากางกันสาดไว้ $N$ ผืน กันสาดผืนที่ $i$ คลุมถนนตั้งแต่ระยะ $l_i$ ถึง $r_i$ เมตร (รวมทั้งสองปลาย) และสูงจากพื้น $h_i$ เซนติเมตร กันสาดหลายผืนอาจคลุมซ้อนกันที่ความสูงต่างกันได้ รถส่งของ $Q$ คันจะมาจอดส่งของ คันที่ $j$ จะจอดที่ระยะ $p_j$ คนขับอยากรู้ความสูงของกันสาดที่ต่ำที่สุดเหนือจุดนั้น จะได้รู้ว่ารถของตัวเองลอดได้หรือเปล่า

สำหรับแต่ละ $j$ ให้หาค่าที่น้อยที่สุดของ $h_i$ ในบรรดากันสาดที่ $l_i \leq p_j \leq r_i$ ถ้าไม่มีกันสาดผืนไหนคลุมจุด $p_j$ เลยให้ตอบ $-1$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับจำนวนเต็ม $l_i$, $r_i$ และ $h_i$
บรรทัดสุดท้าย : รับจำนวนเต็ม $Q$ จำนวน คือ $p_1, p_2, \ldots, p_Q$ (ไม่ได้เรียงลำดับ และอาจซ้ำกัน)

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ แสดงความสูงของกันสาดที่ต่ำที่สุดที่คลุมจุด $p_j$ หรือ $-1$ ถ้าไม่มี

{{examples}}

คำอธิบายตัวอย่างที่ 1

จุด $4$ อยู่ใต้กันสาด $[2, 6]$ สูง $5$ และ $[4, 7]$ สูง $3$ จึงตอบ $3$ จุด $6$ มีกันสาด $[6, 6]$ สูง $2$ คลุมอยู่ด้วย จึงตอบ $2$ จุด $7$ อยู่ที่ปลายขวาของ $[4, 7]$ พอดี ยังนับว่าคลุม จึงตอบ $3$ ส่วนจุด $1$ และ $13$ ไม่มีกันสาดเลย

คำอธิบายตัวอย่างที่ 2

คำถามไม่ได้เรียงลำดับ แต่ต้องตอบตามลำดับที่ถาม จุด $5$ อยู่ใต้กันสาดทั้งสองผืน ผืนที่ต่ำกว่าสูง $8$ จุด $10$ และ $0$ อยู่ที่ปลายของ $[0, 10]$ ก็ยังได้ $8$ ส่วนจุด $11$ ไม่มีกันสาด

Constraints :

  • $1 \leq N, Q \leq 5 \times 10^4$
  • $0 \leq l_i \leq r_i \leq 10^9$
  • $1 \leq h_i \leq 10^9$
  • $0 \leq p_j \leq 10^9$
