Shortest Segment

ถนนสายหนึ่งแบ่งเป็น $N$ ช่องเรียงกัน ช่องที่ $i$ มีเหรียญวางอยู่ $a_i$ เหรียญ และทุกช่องมีเหรียญอย่างน้อยหนึ่งเหรียญ น้องนนท์ต้องเก็บเหรียญให้ได้อย่างน้อย $S$ เหรียญเพื่อแลกตุ๊กตาตัวใหญ่ กติกาคือเลือกจุดเริ่มได้ตามใจ แต่ต้องเดินเก็บช่องที่ติดกันทุกช่องไปทางเดียว แดดร้อนมาก น้องนนท์จึงอยากเดินให้สั้นที่สุดเท่าที่จะทำได้

ให้ลำดับ $a_1, a_2, \ldots, a_N$ ซึ่งเป็นจำนวนเต็มบวกทั้งหมด และจำนวนเต็ม $S$ จงหาความยาวที่สั้นที่สุด $r - l + 1$ ของช่วง $[l, r]$ ที่ $a_l + a_{l+1} + \cdots + a_r \geq S$ ถ้าไม่มีช่วงไหนเลยที่เก็บได้ครบ ให้ตอบ $-1$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $S$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงความยาวของช่วงที่สั้นที่สุดที่มีผลรวมอย่างน้อย $S$ หรือ $-1$ ถ้าไม่มี

{{examples}}

คำอธิบายตัวอย่างที่ 1

ต้องการ $S = 15$ เหรียญ ช่วง $[5, 10]$ ยาวแค่ $2$ ช่องแต่ได้ $15$ พอดี ไม่มีช่องไหนช่องเดียวที่มีถึง $15$ เหรียญ คำตอบจึงเป็น $2$

คำอธิบายตัวอย่างที่ 2

ทั้งถนนมีเหรียญรวมแค่ $6$ เหรียญ ไม่ถึง $S = 7$ จึงตอบ $-1$

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq a_i \leq 10^9$
  • $1 \leq S \leq 10^{15}$
