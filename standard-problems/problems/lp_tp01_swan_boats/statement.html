Swan Boats

วันทัศนศึกษา น้องนนท์พาเพื่อนทั้งห้อง $N$ คน (รวมตัวเองแล้ว) ไปถีบเรือหงส์ที่สวนสาธารณะ เรือหงส์แต่ละลำนั่งได้ไม่เกิน 2 คน และรับน้ำหนักรวมได้ไม่เกิน $K$ กิโลกรัม ค่าเช่าคิดเป็นลำ น้องนนท์ซึ่งเป็นเหรัญญิกห้องจึงอยากจัดคนลงเรือให้ใช้เรือน้อยลำที่สุด ครูให้ทุกคนยืนเข้าแถวเรียงตามน้ำหนักจากเบาไปหนักรอไว้แล้ว

ให้น้ำหนัก $a_1 \leq a_2 \leq \ldots \leq a_N$ และจำนวนเต็ม $K$ ทุกคนต้องได้ลงเรือ เรือแต่ละลำมีคน $1$ หรือ $2$ คน และน้ำหนักรวมของคนในลำต้องไม่เกิน $K$ จงหาจำนวนเรือที่น้อยที่สุด

รับประกันว่าทุกคนหนักไม่เกิน $K$ จึงนั่งเรือคนเดียวได้เสมอ

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $K$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$ ซึ่งเรียงจากน้อยไปมากแล้ว

Output :

มีบรรทัดเดียว แสดงจำนวนเรือที่น้อยที่สุด

{{examples}}

คำอธิบายตัวอย่างที่ 1

คนหนัก $90$ จับคู่กับใครก็เกิน $100$ จึงต้องนั่งคนเดียว ที่เหลือจัดเป็น $(30, 70)$, $(40, 60)$ และ $50$ นั่งคนเดียว รวม $4$ ลำ จะใช้แค่ $3$ ลำไม่ได้ เพราะเมื่อคนหนัก $90$ นั่งคนเดียวแล้ว อีก $5$ คนที่เหลือต้องใช้อย่างน้อย $3$ ลำ

คำอธิบายตัวอย่างที่ 2

ทุกคนหนัก $5$ จับคู่กันได้หมดพอดี ใช้ $2$ ลำ

Constraints :

  • $1 \leq N \leq 2 \cdot 10^5$
  • $1 \leq a_1 \leq a_2 \leq \ldots \leq a_N \leq K \leq 10^9$
