Secret Code

พี่นนท์มีสติกเกอร์ $M$ แบบ ติดหมายเลข $1, 2, \ldots, M$ ไว้ เวลาจะส่งข้อความลับให้น้องในชมรม พี่นนท์จะเขียนหมายเลขสติกเกอร์ต่อกันเป็นสายตัวเลขยาว ๆ โดยไม่เว้นวรรค น้องที่ได้รับจึงต้องเดาเองว่าตัดตรงไหนบ้าง และถ้าตัดได้หลายแบบก็อ่านได้หลายความหมาย น้องอยากรู้ว่าสายตัวเลขนี้อ่านได้ทั้งหมดกี่แบบ

ให้สายตัวเลข $s$ ยาว $N$ ตัว จงหาจำนวนวิธีแบ่งสายตัวเลข $s$ ออกเป็นชิ้นที่ติดกัน (ทุกตัวอยู่ในชิ้นใดชิ้นหนึ่งพอดี ห้ามสลับลำดับ) โดยทุกชิ้นต้อง

  • ไม่ขึ้นต้นด้วยเลข $0$ (ชิ้น 05 หรือ 0 ใช้ไม่ได้)
  • มีค่าเป็นจำนวนเต็มตั้งแต่ $1$ ถึง $M$

สองวิธีถือว่าต่างกันถ้าตำแหน่งที่ตัดต่างกัน เนื่องจากคำตอบอาจมีค่ามาก ให้ตอบเป็นเศษจากการหารด้วย $10^9 + 7$ ถ้าแบ่งไม่ได้เลยให้ตอบ $0$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $M$
บรรทัดที่สอง : รับสายตัวเลข $s$ ยาว $N$ ตัว แต่ละตัวเป็นเลขโดด 0 ถึง 9 เขียนติดกันไม่มีช่องว่าง

Output :

มีบรรทัดเดียว แสดงจำนวนวิธีแบ่ง หารเอาเศษด้วย $10^9 + 7$

{{examples}}

คำอธิบายตัวอย่างที่ 1

หมายเลข $1$, $11$ และ $111$ ใช้ได้ทั้งหมด จึงแบ่ง 11111 ได้ $13$ วิธี เช่น 1|1|1|1|1, 11|111, 111|1|1 และ 1|11|11

คำอธิบายตัวอย่างที่ 2

เลข $0$ ต้องอยู่ต่อท้ายชิ้นที่ขึ้นต้นด้วยเลขอื่น ชิ้นแรกจึงต้องเป็น 100 ซึ่งไม่เกิน $M = 100$ แล้วตามด้วย 1 ได้วิธีเดียว ส่วน 10|01 ใช้ไม่ได้เพราะ 01 ขึ้นต้นด้วย $0$

คำอธิบายตัวอย่างที่ 3

เลข $0$ ต้องติดกับเลข $3$ ข้างหน้า แต่ $30 > 26$ และ $301 > 26$ จึงแบ่งไม่ได้เลย

Constraints :

  • $1 \leq N \leq 2 \times 10^5$
  • $1 \leq M \leq 999$
  • $s$ ประกอบด้วยเลขโดด $0$ ถึง $9$ เท่านั้น
