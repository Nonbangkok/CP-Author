Chant Counter

ในการแข่งฟุตบอลประเพณี กองเชียร์ตะโกนเชียร์ไม่หยุดตลอดเกม น้องนนท์อัดเสียงไว้แล้วแปลงเป็นตัวอักษรได้เป็นสตริงยาว $T$ เขาอยากรู้ว่าท่อนเชียร์โปรด $P$ ถูกตะโกนไปกี่ครั้ง โดยนับทุกตำแหน่งที่ $P$ ปรากฏเป็นสตริงย่อยที่ติดกันของ $T$ และนับแบบที่ซ้อนทับกันได้ เช่น ใน aaaa มี aa อยู่ $3$ ครั้ง (เริ่มที่ตัวที่ $1$, $2$ และ $3$)

พูดอีกอย่างคือ ให้นับจำนวนตำแหน่ง $i$ ที่ $1 \leq i \leq |T| - |P| + 1$ และ $T_i T_{i+1} \ldots T_{i+|P|-1} = P$

Input :

บรรทัดแรก : รับสตริง $T$
บรรทัดที่สอง : รับสตริง $P$
ทั้งสองสตริงประกอบด้วยตัวอักษรภาษาอังกฤษพิมพ์เล็กเท่านั้น

Output :

มีบรรทัดเดียว แสดงจำนวนครั้งที่ $P$ ปรากฏใน $T$

{{examples}}

คำอธิบายตัวอย่างที่ 1

gogo ปรากฏใน gogogoalgogo ที่ตำแหน่งเริ่ม $1$, $3$ และ $9$ สองครั้งแรกใช้ตัวอักษร go ตรงกลางร่วมกัน ซึ่งนับทั้งคู่ ตอบ $3$

คำอธิบายตัวอย่างที่ 2

aa เริ่มได้ที่ตำแหน่ง $1, 2, 3, 4$ ของ aaaaa ตอบ $4$

Constraints :

  • $1 \leq |P| \leq |T| \leq 10^6$
  • $T$ และ $P$ มีแต่ตัวอักษร a ถึง z
