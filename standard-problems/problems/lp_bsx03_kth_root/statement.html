K-th Root

น้องนนท์เพิ่งรู้ว่าเครื่องคิดเลขในห้องเรียนคิดรากที่ $k$ ของเลขใหญ่ ๆ ผิด เพราะมันใช้ทศนิยมซึ่งปัดเศษคลาดเคลื่อนได้ เช่นบางครั้งรากที่สองของ $10^{18} - 1$ ออกมาเป็น $10^9$ ซึ่งผิด เพราะ $(10^9)^2 = 10^{18}$ มากกว่า $10^{18} - 1$ น้องนนท์จึงอยากได้โปรแกรมที่ใช้แค่จำนวนเต็มและตอบถูกเสมอ

มีคำถาม $Q$ ข้อ แต่ละข้อให้จำนวนเต็ม $n$ และ $k$ จงหาจำนวนเต็มบวกที่มากที่สุด $x$ ที่ทำให้ $x^k \leq n$ หรือก็คือ $\lfloor \sqrt[k]{n} \rfloor$

ระวังว่า $x^k$ ของ $x$ ที่ลองอาจใหญ่เกินกว่าที่ long long เก็บได้ ถ้าคูณจนล้น โปรแกรมจะถูกจับได้และได้ผลเป็น Runtime Error

Input :

บรรทัดแรก : รับจำนวนเต็ม $Q$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $n_j$ และ $k_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงจำนวนเต็มบวก $x$ ที่มากที่สุดที่ $x^{k_j} \leq n_j$

{{examples}}

คำอธิบายตัวอย่างที่ 1

$\lfloor \sqrt{10} \rfloor = 3$ เพราะ $3^2 = 9 \leq 10$ แต่ $4^2 = 16$ รากที่สามของ $27$ คือ $3$ พอดี ส่วน $26$ ได้ $2$ เพราะ $3^3 = 27$ เกิน $26$ ไปแล้ว และ $2^{60}$ มากกว่า $10^{18}$ ทำให้รากที่ $60$ ของ $10^{18}$ คือ $1$

Constraints :

  • $1 \leq Q \leq 10^4$
  • $1 \leq n_j \leq 10^{18}$
  • $2 \leq k_j \leq 60$
