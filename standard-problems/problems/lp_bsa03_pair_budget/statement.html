Pair Budget

ก่อนวันเกิดเพื่อน น้องนนท์เดินเข้าร้านของขวัญที่มีของ $N$ ชิ้น ชิ้นที่ $i$ ราคา $a_i$ บาท น้องนนท์ตั้งใจจะซื้อของสองชิ้นที่ต่างกันไปให้ และมีงบอยู่ $K$ บาท เขาอยากรู้ว่ามีวิธีเลือกของสองชิ้นได้กี่แบบที่ราคารวมไม่เกินงบ จะได้รู้ว่ามีตัวเลือกเยอะแค่ไหน

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และจำนวนเต็ม $K$ จงนับจำนวนคู่ดัชนี $(i, j)$ ที่ $1 \leq i < j \leq N$ และ $a_i + a_j \leq K$

ราคาอาจซ้ำกันได้ ของสองชิ้นที่ราคาเท่ากันแต่เป็นคนละชิ้นนับเป็นคู่ที่ต่างกัน ราคาอาจติดลบได้ (ร้านแถมคูปองให้) และลำดับที่ให้มายังไม่ได้เรียง ระวังว่าคำตอบอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $K$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนคู่ $(i, j)$ ที่ $i < j$ และ $a_i + a_j \leq K$

{{examples}}

คำอธิบายตัวอย่างที่ 1

คู่ที่ราคารวมไม่เกิน $10$ คือ $(1, 2)$ ราคา $3 + 7 = 10$, $(1, 4)$ ราคา $3 + 2 = 5$, $(2, 4)$ ราคา $7 + 2 = 9$ และ $(4, 5)$ ราคา $2 + 8 = 10$ ส่วนคู่อื่นเกินงบทั้งหมด จึงตอบ $4$

ในตัวอย่างที่ 2 ของทั้งสามชิ้นราคา $5$ เท่ากัน ทุกคู่ราคารวม $10 \leq 10$ ได้ทั้งหมด $3$ คู่

Constraints :

  • $1 \leq N \leq 10^5$
  • $-10^9 \leq a_i \leq 10^9$
  • $-2 \cdot 10^9 \leq K \leq 2 \cdot 10^9$
