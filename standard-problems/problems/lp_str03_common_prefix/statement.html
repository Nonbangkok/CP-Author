Reading in Sync

ครูให้นักเรียนสองคนอ่านออกเสียงพร้อมกันจากม้วนกระดาษยาวที่เขียนตัวอักษรภาษาอังกฤษพิมพ์เล็กไว้ $N$ ตัว เป็นสตริง $s = s_1 s_2 \ldots s_N$ แต่ทั้งสองคนชอบเริ่มคนละที่ คนแรกเริ่มอ่านที่ตัวอักษรตัวที่ $i$ คนที่สองเริ่มที่ตัวที่ $j$ แล้วอ่านไปทางขวาทีละตัวพร้อมกัน เสียงจะประสานกันจนกว่าจะอ่านตัวอักษรต่างกัน หรือจนกว่าจะมีคนอ่านถึงท้ายม้วน

ครูอยากรู้ $Q$ ครั้ง ครั้งละหนึ่งคู่ $(i, j)$ ว่าทั้งสองคนอ่านพร้อมกันได้กี่ตัวอักษร พูดอีกอย่างคือ จงหาค่า $k$ ที่มากที่สุดซึ่ง $s_{i+t} = s_{j+t}$ สำหรับทุก $0 \leq t \lt k$ โดย $i + k - 1 \leq N$ และ $j + k - 1 \leq N$ (ความยาวของ prefix ร่วมที่ยาวที่สุดของ suffix ที่เริ่มที่ $i$ กับ suffix ที่เริ่มที่ $j$)

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับสตริง $s$ ยาว $N$ ตัวอักษร ประกอบด้วยตัวอักษรภาษาอังกฤษพิมพ์เล็กเท่านั้น
อีก $Q$ บรรทัดถัดมา : บรรทัดละคำถาม รับจำนวนเต็ม $i$ และ $j$

Output :

มีทั้งหมด $Q$ บรรทัด โดยบรรทัดที่ $q$ แสดงจำนวนตัวอักษรที่อ่านพร้อมกันได้ของคำถามที่ $q$

คำอธิบายตัวอย่างที่ 1

คำถามแรก คนแรกอ่าน abracadabra คนที่สองอ่าน abra พร้อมกันได้ $4$ ตัวแล้วคนที่สองก็อ่านถึงท้ายม้วน คำถามที่สอง bracadabra กับ bra ได้ $3$ คำถามที่สาม abracadabra กับ acadabra ตรงกันแค่ตัวแรก ได้ $1$ คำถามสุดท้ายเริ่มที่เดียวกัน อ่านด้วยกันจนจบได้ $7$ ตัว

คำอธิบายตัวอย่างที่ 2

ทุกตัวเป็น a ตัวอักษรไม่เคยต่างกันเลย จำนวนที่อ่านได้จึงขึ้นกับว่าใครถึงท้ายม้วนก่อน

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq Q \leq 5 \times 10^4$
  • $1 \leq i, j \leq N$ ($i$ อาจเท่ากับ $j$)
  • $s$ มีแต่ตัวอักษร a ถึง z
