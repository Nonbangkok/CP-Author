Taller in Front

นักเรียน $N$ คนเข้าแถวหน้าเสาธงเรียงจากหน้าไปหลัง คนที่ $i$ สูง $a_i$ เซนติเมตร คุณครูอยากให้แถวเรียงจากเตี้ยไปสูง แต่ก่อนจะจัดใหม่ คุณครูอยากรู้ว่าตอนนี้แถว "มั่ว" แค่ไหน จึงนับจำนวนคู่ของนักเรียนที่คนหนึ่งยืนอยู่ข้างหน้าและสูงกว่าอีกคน

ให้ลำดับ $a_1, a_2, \ldots, a_N$ จงนับจำนวนคู่ $(i, j)$ ที่ $i < j$ และ $a_i > a_j$ คนที่สูงเท่ากันไม่นับเป็นคู่

ระวังว่าคำตอบอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนคู่ที่นับได้

{{examples}}

คำอธิบายตัวอย่างที่ 1

คนที่ $1$ (สูง $150$) สูงกว่าคนที่ $4$ และ $6$ ที่ยืนข้างหลัง ได้ $2$ คู่ คนที่ $2$ (สูง $162$) สูงกว่าคนที่ $3, 4, 6$ ได้ $3$ คู่ คนที่ $3$ ได้ $2$ คู่ (กับคนที่ $4$ และ $6$) และคนที่ $5$ ได้ $1$ คู่ (กับคนที่ $6$) รวม $8$ คู่ ส่วนคนที่ $2$ กับคนที่ $5$ สูงเท่ากันจึงไม่นับ

คำอธิบายตัวอย่างที่ 2

ทุกคนสูงเท่ากัน ไม่มีคู่ไหนนับได้เลย

Constraints :

  • $1 \leq N \leq 10^5$
  • $1 \leq a_i \leq 10^9$
