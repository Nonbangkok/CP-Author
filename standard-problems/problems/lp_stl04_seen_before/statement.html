น้องนนท์เป็นผู้ดูแลแชทของห้องเรียน ทุกครั้งที่มีคนพิมพ์คำหนึ่งคำเข้ามา บอตของห้องจะตอบกลับทันทีว่าคำนี้ถูกพิมพ์มาแล้วกี่ครั้ง นับรวมครั้งนี้ด้วย ถ้าเป็นครั้งแรกบอตตอบ $1$ ถ้ามีคนเคยพิมพ์คำเดียวกันมาแล้วสองครั้ง บอตตอบ $3$

ให้คำ $w_1, w_2, \ldots, w_N$ ตามลำดับที่ถูกพิมพ์ จงเขียนบอตตัวนี้ให้น้องนนท์ คือสำหรับแต่ละ $i$ ให้แสดงจำนวนดัชนี $j \leq i$ ที่ $w_j = w_i$

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
$N$ บรรทัดถัดมา : บรรทัดที่ $i$ รับคำ $w_i$

Output :

มีทั้งหมด $N$ บรรทัด โดย
บรรทัดที่ $i$ $(1 \leq i \leq N)$ แสดงคำตอบของบอตเมื่อมีคนพิมพ์ $w_i$

{{examples}}

คำอธิบายตัวอย่างที่ 1

คำ hi ถูกพิมพ์ที่ตำแหน่ง $1, 3$ และ $6$ บอตจึงตอบ $1, 2, 3$ ที่ตำแหน่งเหล่านั้น คำ bye ถูกพิมพ์ที่ตำแหน่ง $2$ และ $5$ ส่วน hii เป็นคนละคำกับ hi จึงได้ $1$

Constraints :

  • $1 \leq N \leq 50{,}000$
  • แต่ละคำยาว $1$ ถึง $10$ ตัวอักษร และประกอบด้วยตัวอักษรภาษาอังกฤษพิมพ์เล็กเท่านั้น
