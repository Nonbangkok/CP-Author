Bird Species

ชมรมดูนกของโรงเรียนไปเดินป่าตามเส้นทางศึกษาธรรมชาติที่มีจุดชมนก $N$ จุด เรียงเป็นแนวตรงหมายเลข $1$ ถึง $N$ ที่จุดที่ $i$ น้อง ๆ ถ่ายรูปนกได้หนึ่งตัวและจดรหัสชนิดของมันไว้เป็นจำนวนเต็ม $a_i$ นกชนิดเดียวกันได้รหัสเดียวกัน และนกชนิดเดียวกันอาจถูกพบหลายจุด

กลับมาแล้ว ประธานชมรมมีคำถาม $Q$ ข้อ ข้อที่ $j$ ถามว่า ถ้านับเฉพาะจุดที่ $l_j$ ถึงจุดที่ $r_j$ (รวมทั้งสองจุด) มีนกกี่ชนิดที่แตกต่างกัน หรือก็คือในบรรดา $a_{l_j}, a_{l_j + 1}, \ldots, a_{r_j}$ มีค่าที่ไม่ซ้ำกันกี่ค่า

รหัสชนิดนกอาจเป็นเลขที่ใหญ่มาก (สูงสุด $10^9$) คำถามทุกข้ออยู่ใน input ตั้งแต่แรก และต้องพิมพ์คำตอบตามลำดับที่ถาม

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $l_j$ และ $r_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ แสดงจำนวนชนิดนกที่แตกต่างกันในจุดที่ $l_j$ ถึง $r_j$

{{examples}}

คำอธิบายตัวอย่างที่ 1

ทั้งเส้นทางมีนกรหัส $3, 1, 7, 9$ รวม $4$ ชนิด จุดที่ $2$ ถึง $6$ คือ $1, 3, 7, 1, 1$ มี $3$ ชนิด จุดที่ $5$ ถึง $6$ เป็นรหัส $1$ ทั้งคู่ จึงมีชนิดเดียว และจุดที่ $4$ ถึง $7$ คือ $7, 1, 1, 9$ มี $3$ ชนิด

คำอธิบายตัวอย่างที่ 2

จุดที่ $1$ ถึง $3$ มีรหัส $10^9$ กับ $5$ รวม $2$ ชนิด คำถามเดิมถามซ้ำได้ และคำถามที่ $l_j = r_j$ ตอบ $1$ เสมอ

Constraints :

  • $1 \leq N, Q \leq 5 \times 10^4$
  • $1 \leq a_i \leq 10^9$
  • $1 \leq l_j \leq r_j \leq N$
