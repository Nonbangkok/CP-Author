Range Sums

ร้านชานมของพี่นนท์จดกำไรของแต่ละวันไว้ $N$ วัน วันไหนขายดีก็ได้กำไรเป็นบวก วันไหนฝนตกจนต้องเททิ้งก็ขาดทุนเป็นลบ ทีนี้หุ้นส่วนของร้านมีคำถามเข้ามา $Q$ ข้อ แต่ละข้ออยากรู้ยอดขายรวมตั้งแต่วันที่ $l$ ถึงวันที่ $r$

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และคำถาม $Q$ ข้อ คำถามที่ $j$ ประกอบด้วยจำนวนเต็ม $l_j$ และ $r_j$ โดย $1 \leq l_j \leq r_j \leq N$ จงหาผลรวม $a_{l_j} + a_{l_j + 1} + \cdots + a_{r_j}$ คำถามเยอะและช่วงก็ยาว ถ้าไล่บวกใหม่ทุกคำถามจะไม่ทันเวลา

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $l_j$ และ $r_j$

Output :

มีทั้งหมด $Q$ บรรทัด โดย
บรรทัดที่ $j$ $(1 \leq j \leq Q)$ แสดงผลรวมของคำถามที่ $j$

{{examples}}

คำอธิบายตัวอย่างที่ 1

คำถามแรกคือ $a_2 + a_3 + a_4 = -2 + 7 + 1 = 6$ คำถามที่สองถามทั้งลำดับ ได้ $3 - 2 + 7 + 1 + 4 = 13$ ส่วนคำถามที่สามมีวันเดียวคือ $a_2 = -2$

Constraints :

  • $1 \leq N, Q \leq 40{,}000$
  • $-10^6 \leq a_i \leq 10^6$
  • $1 \leq l_j \leq r_j \leq N$
