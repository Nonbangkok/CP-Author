Split the Work

ชมรมคอมพิวเตอร์ต้องตรวจข้อสอบค่าย $N$ ชุดที่วางเรียงกันเป็นแถวบนโต๊ะยาว ชุดที่ $i$ ต้องใช้เวลาตรวจ $a_i$ นาที พี่นนท์มีผู้ช่วย $K$ คน และอยากแบ่งข้อสอบให้แต่ละคนรับไปเป็นช่วงที่ติดกัน (จะได้ไม่ต้องเดินสลับไปมา) ทุกคนเริ่มตรวจพร้อมกัน งานจะเสร็จเมื่อคนที่ได้งานหนักที่สุดตรวจเสร็จ พี่นนท์จึงอยากแบ่งให้งานที่หนักที่สุดของแต่ละคนเบาที่สุดเท่าที่ทำได้

ให้ลำดับ $a_1, a_2, \ldots, a_N$ และจำนวนเต็ม $K$ จงแบ่งลำดับออกเป็นไม่เกิน $K$ ช่วงที่ติดกัน โดยทุกสมาชิกต้องอยู่ในช่วงใดช่วงหนึ่งพอดี ให้ผลรวมของช่วงที่มากที่สุดมีค่าน้อยที่สุด แล้วแสดงค่านั้น (ผู้ช่วยบางคนอาจไม่ได้งานเลยก็ได้)

ระวังว่าผลรวมของช่วงอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $K$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงผลรวมของช่วงที่มากที่สุดซึ่งมีค่าน้อยที่สุดที่เป็นไปได้

{{examples}}

คำอธิบายตัวอย่างที่ 1

แบ่งเป็น $[7, 2, 5]$, $[10]$ และ $[8]$ ได้ผลรวม $14, 10, 8$ ค่าที่มากที่สุดคือ $14$ ถ้าจะให้ทุกช่วงไม่เกิน $13$ ช่วงแรกจะใส่ได้แค่ $7, 2$ (เพราะ $7 + 2 + 5 = 14$) แล้ว $5$ กับ $10$ ก็อยู่ด้วยกันไม่ได้ จะต้องใช้อย่างน้อยสี่ช่วง จึงตอบ $14$

ในตัวอย่างที่ 2 มีผู้ช่วยแค่คนเดียว ต้องตรวจทั้งหมดเอง จึงตอบผลรวมทั้งหมดคือ $3{,}000{,}000{,}000$

Constraints :

  • $1 \leq K \leq N \leq 10^5$
  • $1 \leq a_i \leq 10^9$
