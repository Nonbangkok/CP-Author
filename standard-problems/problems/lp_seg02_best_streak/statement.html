Best Streak

พี่นนท์เปิดร้านขายของออนไลน์มาแล้ว $N$ วัน วันที่ $i$ ได้กำไร $a_i$ บาท ซึ่งติดลบได้ (วันที่ขาดทุน) ฝ่ายบัญชีชอบแก้ตัวเลขย้อนหลังอยู่บ่อย ๆ ส่วนฝ่ายการตลาดชอบถามว่า ถ้าดูแค่ตั้งแต่วันที่ $l$ ถึงวันที่ $r$ แล้วผลรวมกำไรของช่วงวันติดกันที่ดีที่สุดคือเท่าไร จะได้เอาไปโฆษณาว่า "ขายดีต่อเนื่อง"

เริ่มต้นกำไรของวันที่ $i$ คือ $a_i$ จากนั้นมีเหตุการณ์ $Q$ อย่างเกิดขึ้นตามลำดับ แต่ละอย่างเป็นแบบใดแบบหนึ่ง

  • 1 i x : แก้กำไรของวันที่ $i$ ให้เป็น $x$
  • 2 l r : ให้หาค่ามากที่สุดของ $a_s + a_{s+1} + \cdots + a_e$ ในบรรดาทุกคู่ $s, e$ ที่ $l \leq s \leq e \leq r$

ช่วงที่เลือกต้องมีอย่างน้อยหนึ่งวัน ถ้าทุกวันในช่วงขาดทุน คำตอบก็จะติดลบ และระวังว่าผลรวมอาจใหญ่เกินกว่าที่ int เก็บได้

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $Q$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$
$Q$ บรรทัดถัดมา : แต่ละบรรทัดเป็นเหตุการณ์หนึ่งอย่าง ในรูป 1 i x หรือ 2 l r ตามลำดับที่เกิด

Output :

สำหรับเหตุการณ์แบบ 2 แต่ละครั้ง ให้แสดงผลรวมที่มากที่สุดบรรทัดละหนึ่งคำตอบ ตามลำดับที่ถาม

{{examples}}

คำอธิบายตัวอย่างที่ 1

กำไรคือ $3, -5, 4, -1, 2, -6, 1$ คำถาม $[1, 7]$ ได้ $4 + (-1) + 2 = 5$ จากวันที่ $3$ ถึง $5$ คำถาม $[1, 2]$ ได้ $3$ จากวันที่ $1$ วันเดียว ถ้ารวมวันที่ $2$ ด้วยจะลดลง จากนั้นวันที่ $2$ ถูกแก้เป็น $5$ คำถาม $[1, 4]$ จึงได้ $3 + 5 + 4 = 12$ ส่วนคำถาม $[6, 6]$ มีวันเดียวที่ขาดทุน ต้องตอบ $-6$

คำอธิบายตัวอย่างที่ 2

ทุกวันขาดทุน ช่วงที่ดีที่สุดจึงเป็นวันเดียวที่ขาดทุนน้อยที่สุดในช่วงนั้น

Constraints :

  • $1 \leq N, Q \leq 5 \times 10^4$
  • $-10^9 \leq a_i, x \leq 10^9$
  • $1 \leq i \leq N$ และ $1 \leq l \leq r \leq N$
  • มีเหตุการณ์แบบ 2 อย่างน้อยหนึ่งครั้ง
