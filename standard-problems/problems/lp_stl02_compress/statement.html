Coordinate Compression

น้องนนท์เก็บสถิติความสูงของต้นไม้ในสวนไว้ $N$ ต้น ตัวเลขมีทั้งติดลบ (วัดจากขอบบ่อ) และใหญ่ระดับพันล้าน เขียนลงตารางแล้วดูยากมาก น้องนนท์เลยอยากเปลี่ยนตัวเลขแต่ละตัวให้เหลือแค่ลำดับที่ของมัน เพราะสิ่งที่สนใจจริง ๆ คือใครสูงกว่าใคร ไม่ใช่สูงเท่าไร

ให้ลำดับ $a_1, a_2, \ldots, a_N$ ให้นำค่าที่ต่างกันทั้งหมดมาเรียงจากน้อยไปมาก แล้วให้เลขกำกับตามลำดับ ค่าที่น้อยที่สุดได้เลข $1$ ค่าถัดไปได้เลข $2$ ไปเรื่อย ๆ จากนั้นแทนแต่ละ $a_i$ ด้วยเลขกำกับของค่านั้น เรียกว่า $b_i$ ค่าที่เท่ากันจึงได้เลขเดียวกันเสมอ

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

บรรทัดแรก : แสดงจำนวนค่าที่ต่างกัน $D$
บรรทัดที่สอง : แสดง $b_1, b_2, \ldots, b_N$ คั่นด้วยช่องว่าง

คำอธิบายตัวอย่างที่ 1

ค่าที่ต่างกันเรียงจากน้อยไปมากคือ $-7, 3, 50, 1000000000$ มีทั้งหมด $4$ ค่า จึงได้เลข $1, 2, 3, 4$ ตามลำดับ ค่า $50$ ปรากฏสองครั้ง ทั้งสองตำแหน่งจึงได้เลข $3$

Constraints :

  • $1 \leq N \leq 50{,}000$
  • $-10^9 \leq a_i \leq 10^9$
