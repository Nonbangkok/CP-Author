Nearest Van

บริษัทรถตู้ของน้องนนท์มีรถจอดรอผู้โดยสารอยู่ริมทางหลวงสายยาวเส้นหนึ่ง แต่ละคันจอดอยู่ที่หลักกิโลเมตรใดกิโลเมตรหนึ่ง และหลายคันอาจจอดที่หลักเดียวกันได้ ทั้งวันมีรถเข้ามาจอดเพิ่มและมีรถออกไปส่งผู้โดยสาร ทุกครั้งที่มีผู้โดยสารโทรมา น้องนนท์ต้องรีบส่งรถคันที่จอดใกล้ผู้โดยสารที่สุดไปรับ

เริ่มต้นไม่มีรถจอดอยู่เลย จากนั้นมีเหตุการณ์ $Q$ เหตุการณ์ตามลำดับ แต่ละเหตุการณ์เป็นแบบใดแบบหนึ่ง

  • 1 x : มีรถเข้ามาจอดที่หลักกิโลเมตร $x$ หนึ่งคัน
  • 2 x : รถที่จอดอยู่ที่หลักกิโลเมตร $x$ ออกไปหนึ่งคัน รับประกันว่าตอนนั้นมีรถจอดที่ $x$ อย่างน้อยหนึ่งคัน ถ้ามีหลายคันก็ออกไปแค่คันเดียว
  • 3 x : ผู้โดยสารอยู่ที่หลักกิโลเมตร $x$ ให้แสดงหลักกิโลเมตร $v$ ของรถที่ทำให้ $|v - x|$ น้อยที่สุด ถ้ามีสองคันที่ห่างเท่ากัน ให้แสดงหลักที่น้อยกว่า และถ้าไม่มีรถจอดอยู่เลยให้แสดง $-1$ (เหตุการณ์นี้แค่ถาม รถยังจอดอยู่ที่เดิม)

Input :

บรรทัดแรก : รับจำนวนเต็ม $Q$
$Q$ บรรทัดถัดมา : บรรทัดที่ $j$ รับจำนวนเต็ม $t_j$ และ $x_j$ คือชนิดของเหตุการณ์และหลักกิโลเมตร

Output :

สำหรับเหตุการณ์ชนิด $3$ แต่ละครั้ง ให้แสดงคำตอบหนึ่งบรรทัด ตามลำดับของเหตุการณ์

{{examples}}

คำอธิบายตัวอย่างที่ 1

หลังสามเหตุการณ์แรกมีรถจอดที่ $10, 20, 20$ ผู้โดยสารที่ $14$ ได้รถที่ $10$ (ห่าง $4$) ผู้โดยสารที่ $15$ ห่างจาก $10$ และ $20$ เท่ากันคือ $5$ จึงได้หลักที่น้อยกว่าคือ $10$ จากนั้นรถที่ $10$ ออกไป และรถที่ $20$ ออกไปหนึ่งคัน จึงเหลือรถที่ $20$ หนึ่งคัน ผู้โดยสารที่ $0$ จึงได้ $20$ สุดท้ายรถคันที่เหลือออกไป ไม่มีรถจอดเลย จึงตอบ $-1$

Constraints :

  • $1 \leq Q \leq 100{,}000$
  • $t_j \in \{1, 2, 3\}$
  • $0 \leq x_j \leq 10^9$
