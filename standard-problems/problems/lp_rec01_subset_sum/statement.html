Exact Change

น้องนนท์ไปซื้อชานมไข่มุกราคา $S$ บาท ร้านนี้ขี้งกมาก ไม่มีเงินทอน ในกระเป๋าน้องนนท์มีเหรียญอยู่ $N$ เหรียญ (เหรียญในเรื่องนี้มีมูลค่าเท่าไรก็ได้ ไม่จำเป็นต้องเป็น 1, 2, 5, 10 บาทแบบของจริง) น้องนนท์เลยสงสัยว่ามีกี่วิธีที่จะหยิบเหรียญออกมาจ่ายให้ได้พอดีเป๊ะ

ให้เหรียญ $N$ เหรียญ เหรียญที่ $i$ มีมูลค่า $a_i$ บาท จงนับจำนวนวิธีเลือกเหรียญ (เลือกกี่เหรียญก็ได้ แต่ละเหรียญเลือกได้ไม่เกินหนึ่งครั้ง) ที่ผลรวมมูลค่าเท่ากับ $S$ พอดี

สองวิธีถือว่าต่างกันเมื่อชุดของหมายเลขเหรียญที่เลือกต่างกัน ถึงแม้มูลค่ารวมของเหรียญจะเหมือนกันก็ตาม เช่น ถ้า $a_1 = a_2 = 5$ การเลือกเหรียญที่ $1$ กับการเลือกเหรียญที่ $2$ นับเป็นสองวิธี

Input :

บรรทัดแรก : รับจำนวนเต็ม $N$ และ $S$
บรรทัดที่สอง : รับจำนวนเต็ม $N$ จำนวน คือ $a_1, a_2, \ldots, a_N$

Output :

มีบรรทัดเดียว แสดงจำนวนวิธีเลือกเหรียญที่ผลรวมเท่ากับ $S$ พอดี (ถ้าไม่มีเลยให้ตอบ $0$)

{{examples}}

คำอธิบายตัวอย่างที่ 1

เหรียญมีมูลค่า $1, 2, 3, 4$ วิธีที่ได้ผลรวม $5$ คือ $\{1, 4\}$ และ $\{2, 3\}$ รวม $2$ วิธี

คำอธิบายตัวอย่างที่ 2

เหรียญมีมูลค่า $5, 5, 10$ วิธีที่ได้ผลรวม $10$ คือ เลือกเหรียญที่ $1$ กับ $2$ หรือเลือกเหรียญที่ $3$ เหรียญเดียว รวม $2$ วิธี

Constraints :

  • $1 \leq N \leq 20$
  • $1 \leq S \leq 2 \times 10^7$
  • $1 \leq a_i \leq 10^6$
