## Fibonacci ตัวที่ไกลมาก ๆ

สมมติโจทย์ถามว่า "จงหา $F_N \bmod (10^9 + 7)$" เมื่อ $F_0 = 0$, $F_1 = 1$ และ $F_n = F_{n-1} + F_{n-2}$ ถ้า $N \leq 10^7$ ลูปธรรมดาที่จำแค่สองพจน์ล่าสุดก็จบ แต่ถ้า $N = 10^{18}$ ลูปนี้ต้องรอเป็นสิบปี ซึ่งคุ้น ๆ ใช่ไหม? ในบท Binary Exponentiation เราเจอปัญหาหน้าตาเดียวกันกับ $a^b$ และแก้ด้วยการยกกำลังสองซ้ำ ๆ จนเหลือแค่ $O(\log b)$ บทนี้จะเอาท่าเดิมมาใช้กับ recurrence แทบทุกแบบที่เป็น **เชิงเส้น** (linear) คือแต่ละพจน์เป็นผลรวมของพจน์ก่อนหน้าคูณค่าคงที่ ทริกคือเปลี่ยน "หนึ่งก้าวของ recurrence" ให้กลายเป็น **การคูณเมทริกซ์หนึ่งครั้ง** แล้วยกกำลังเมทริกซ์นั้น

## ไอเดีย: หนึ่งก้าว = คูณเมทริกซ์หนึ่งครั้ง

ลูปธรรมดานั้นจำค่าไว้แค่สองตัวคือ $(F_n, F_{n-1})$ ก้อนนี้เรียกว่า **สถานะ (state)** ทุกรอบเราสร้างสถานะใหม่จากสถานะเก่า

$$F_{n+1} = 1 \cdot F_n + 1 \cdot F_{n-1} \qquad F_n = 1 \cdot F_n + 0 \cdot F_{n-1}$$

สองสมการนี้เขียนรวมเป็นเมทริกซ์คูณเวกเตอร์ได้พอดี

$$\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} F_n \\ F_{n-1} \end{pmatrix}$$

ตั้งชื่อเมทริกซ์นี้ว่า $M$ เดินหนึ่งก้าวคือคูณ $M$ หนึ่งครั้ง เดิน $n$ ก้าวก็คือคูณ $M$ ไป $n$ ครั้ง

$$\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = M \cdot M \cdots M \begin{pmatrix} F_1 \\ F_0 \end{pmatrix} = M^n \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

จุดสำคัญคือการคูณเมทริกซ์ **มีสมบัติการเปลี่ยนกลุ่ม** (associative): $(AB)C = A(BC)$ เราจึงจัดกลุ่มใหม่ได้ตามใจ เช่น $M^{8} = \big((M^2)^2\big)^2$ ใช้คูณแค่สามครั้ง พูดง่าย ๆ คือ binary exponentiation ใช้กับเมทริกซ์ได้ทุกบรรทัด แค่เปลี่ยน "คูณเลข" เป็น "คูณเมทริกซ์" และเปลี่ยนเลข $1$ ตอนเริ่มเป็น **เมทริกซ์เอกลักษณ์** $I$ (เลข $1$ บนเส้นทแยง นอกนั้น $0$) เพราะ $I \cdot A = A$ เหมือน $1 \cdot a = a$

## ทบทวนการคูณเมทริกซ์

ถ้า $A$ กับ $B$ เป็นเมทริกซ์จัตุรัสขนาด $k \times k$ แล้ว $C = AB$ มีช่อง

$$C_{ij} = \sum_{t=1}^{k} A_{it} \cdot B_{tj}$$

คือเอา **แถว** $i$ ของ $A$ ไปจับคู่กับ **คอลัมน์** $j$ ของ $B$ คูณกันทีละคู่แล้วบวก

```text
          B
        [ 5  6 ]
        [ 7  8 ]
                         C_11 = 1*5 + 2*7 = 19
  A                      C_12 = 1*6 + 2*8 = 22
[ 1  2 ]  ->  [ 19 22 ]  C_21 = 3*5 + 4*7 = 43
[ 3  4 ]      [ 43 50 ]  C_22 = 3*6 + 4*8 = 50
```

แต่ละช่องใช้ $k$ ผลคูณ มีทั้งหมด $k^2$ ช่อง การคูณหนึ่งครั้งจึงเป็น $O(k^3)$ อีกเรื่องที่ต้องจำคือ **สลับที่ไม่ได้** โดยทั่วไป $AB \neq BA$ แต่ไม่ต้องห่วงตอนยกกำลัง เพราะเราคูณแต่ $M$ กับกำลังของ $M$ เอง ซึ่งสลับกันได้เสมอ ($M^a M^b = M^{a+b} = M^b M^a$)

## Template

โค้ดนี้คอมไพล์ได้ทั้งไฟล์ ใช้ `vector<vector<long long>>` จะได้รองรับทุกขนาด $k$ มีทั้งคูณเมทริกซ์ ยกกำลัง และคูณเมทริกซ์กับเวกเตอร์ ส่วน `main` หา $F_N$

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007LL;
using Matrix = vector<vector<long long>>;

// เมทริกซ์ศูนย์ขนาด k x k
Matrix zero(int k) { return Matrix(k, vector<long long>(k, 0)); }

// เมทริกซ์เอกลักษณ์ I (บทบาทเหมือนเลข 1)
Matrix unit(int k) {
  Matrix r = zero(k);
  for (int i = 0; i < k; i++) r[i][i] = 1;
  return r;
}

// C = A * B (mod MOD), O(k^3)
// ทุกช่องของ A, B < MOD ผลคูณหนึ่งคู่ < 1.0e18 บวกกับ c < MOD ยังไม่ล้น long long
// จึง mod หลังบวกทุกครั้ง ห้ามรวมหลายผลคูณก่อนค่อย mod
Matrix multiply(const Matrix &a, const Matrix &b) {
  int k = a.size();
  Matrix c = zero(k);
  for (int i = 0; i < k; i++)
    for (int t = 0; t < k; t++) {
      if (a[i][t] == 0) continue;  // ข้ามศูนย์: เมทริกซ์จากโจทย์มักมีศูนย์เยอะ
      for (int j = 0; j < k; j++) c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % MOD;
    }
  return c;
}

// A^e แบบ binary exponentiation, O(k^3 log e)
Matrix matPow(Matrix a, long long e) {
  Matrix result = unit(a.size());
  while (e > 0) {
    if (e & 1) result = multiply(result, a);
    a = multiply(a, a);
    e >>= 1;
  }
  return result;
}

// w = A * v (เมทริกซ์คูณเวกเตอร์หลัก), O(k^2)
vector<long long> mulVec(const Matrix &a, const vector<long long> &v) {
  int k = a.size();
  vector<long long> w(k, 0);
  for (int i = 0; i < k; i++)
    for (int j = 0; j < k; j++) w[i] = (w[i] + a[i][j] * v[j]) % MOD;
  return w;
}

int main() {
  long long n;
  cin >> n;
  Matrix m = {{1, 1},
              {1, 0}};
  // (F_{n+1}, F_n) = M^n * (F_1, F_0) = M^n * (1, 0)
  vector<long long> v = mulVec(matPow(m, n), {1, 0});
  cout << v[1] << '\n';  // F_n
}
```

ลองใส่ $N = 10$ ได้ $55$ และ $N = 10^{18}$ ได้ $209783453$ ในเสี้ยววินาที

:::note เรื่อง overflow ที่ judge จับได้
ทุกช่องอยู่ในช่วง $[0, 10^9 + 7)$ ผลคูณหนึ่งคู่จึงไม่เกินราว $1.0 \times 10^{18}$ ส่วน `long long` เก็บได้ถึงราว $9.2 \times 10^{18}$ ถ้าบวกผลคูณ **หลายคู่** ก่อนค่อย mod (เช่นรวมครบ $k = 50$ คู่) จะล้นแน่นอน judge ของเราคอมไพล์ด้วย `-fsanitize=signed-integer-overflow` จึงไม่ได้เลขขยะเงียบ ๆ แต่โปรแกรมถูกหยุดทันทีและได้ **Runtime Error** ทางแก้ที่ง่ายสุดคือ mod หลังบวกทุกครั้งแบบใน template (ถ้าอยากรวมหลายคู่ก่อน mod จริง ๆ ให้ใช้ `unsigned long long` ซึ่งรวมได้ราว $18$ คู่ก่อนเกิน $2^{64}$)
:::

## ลองไล่มือ: Fibonacci ตัวที่ 10

$10 = 1010_2$ เริ่มจาก `result` $= I$ และ `a` $= M$ เดินบิตจากขวาไปซ้ายเหมือนตอนยกกำลังเลข

| รอบ | `e` (ฐานสอง) | บิตขวาสุด | `result` หลังรอบ | `a` หลังรอบ |
|---|---|---|---|---|
| 1 | `1010` | 0 | $I$ (ไม่คูณ) | $M^2 = \begin{pmatrix} 2 & 1 \\ 1 & 1 \end{pmatrix}$ |
| 2 | `101` | 1 | $M^2$ | $M^4 = \begin{pmatrix} 5 & 3 \\ 3 & 2 \end{pmatrix}$ |
| 3 | `10` | 0 | $M^2$ (ไม่คูณ) | $M^8 = \begin{pmatrix} 34 & 21 \\ 21 & 13 \end{pmatrix}$ |
| 4 | `1` | 1 | $M^2 \cdot M^8$ | (ไม่ได้ใช้แล้ว) |

รอบสุดท้ายคูณ

$$M^{10} = \begin{pmatrix} 2 & 1 \\ 1 & 1 \end{pmatrix} \begin{pmatrix} 34 & 21 \\ 21 & 13 \end{pmatrix} = \begin{pmatrix} 2 \cdot 34 + 1 \cdot 21 & 2 \cdot 21 + 1 \cdot 13 \\ 34 + 21 & 21 + 13 \end{pmatrix} = \begin{pmatrix} 89 & 55 \\ 55 & 34 \end{pmatrix}$$

แล้ว $M^{10} \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 89 \\ 55 \end{pmatrix}$ คือ $(F_{11}, F_{10})$ ได้ $F_{10} = 55$ ถูกต้อง สังเกตว่า $M^n$ เองก็มี Fibonacci ซ่อนอยู่ครบ: $M^n = \begin{pmatrix} F_{n+1} & F_n \\ F_n & F_{n-1} \end{pmatrix}$ ใช้เช็กโค้ดตัวเองได้ดี

## สร้างเมทริกซ์จาก recurrence ไหนก็ได้

สูตรสำเร็จสำหรับ recurrence ลำดับ $k$

$$f_n = c_1 f_{n-1} + c_2 f_{n-2} + \cdots + c_k f_{n-k}$$

คือใช้สถานะเป็นค่า $k$ ตัวล่าสุด $(f_{n-1}, f_{n-2}, \ldots, f_{n-k})$ แล้วสร้างเมทริกซ์ $k \times k$ ที่ **แถวแรกเป็นสัมประสิทธิ์** $c_1, \ldots, c_k$ (ใช้คำนวณพจน์ใหม่) และ **แถวที่เหลือเป็นเลข $1$ ใต้เส้นทแยง** (เลื่อนค่าเก่าลงไปหนึ่งช่อง ทิ้งตัวที่เก่าที่สุด)

ตัวอย่าง: นับสตริงฐานสองยาว $n$ ที่ **ไม่มี `1` สามตัวติดกัน** ลองแบ่งตามว่าสตริงลงท้ายด้วย `0`, `01` หรือ `011` จะได้ $g_n = g_{n-1} + g_{n-2} + g_{n-3}$ โดย $g_0 = 1$, $g_1 = 2$, $g_2 = 4$

$$\begin{pmatrix} g_n \\ g_{n-1} \\ g_{n-2} \end{pmatrix} = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix} \begin{pmatrix} g_{n-1} \\ g_{n-2} \\ g_{n-3} \end{pmatrix}$$

```cpp
// ใช้ Matrix, matPow, mulVec จาก template ข้างบน
long long countStrings(long long n) {
  vector<long long> base = {4, 2, 1};      // (g_2, g_1, g_0)
  if (n <= 2) return base[2 - n];
  Matrix m = {{1, 1, 1},                   // แถวแรก: สัมประสิทธิ์
              {1, 0, 0},                   // ที่เหลือ: เลื่อนค่าเดิมลงหนึ่งช่อง
              {0, 1, 0}};
  return mulVec(matPow(m, n - 2), base)[0];  // (g_n, g_{n-1}, g_{n-2})
}
```

สังเกตเลขชี้กำลัง: สถานะเริ่มต้นคือ $(g_2, g_1, g_0)$ อยากได้สถานะที่มี $g_n$ อยู่บนสุดต้องเดินอีก $n - 2$ ก้าว จุดนี้แหละที่คนพลาดบ่อยที่สุด วิธีกันพลาดคือลองเทียบกับลูปธรรมดาตอน $n$ เล็ก ๆ ก่อนส่งเสมอ (เช่น $g_5 = 24$)

ถ้าสัมประสิทธิ์ติดลบ เช่น $f_n = 3f_{n-1} - f_{n-2}$ ก็ใส่ $-1$ ในรูป $(10^9 + 7) - 1$ แทน เพราะทุกช่องในเมทริกซ์ต้องอยู่ในช่วง $[0, 10^9 + 7)$

### เมื่อมีค่าคงที่: เพิ่มเลข 1 เข้าไปในสถานะ

แล้วถ้ามีค่าคงที่บวกเข้ามาทุกก้าวล่ะ? ค่าคงที่ไม่ได้มาจากพจน์ก่อนหน้า เมทริกซ์เลยสร้างมันขึ้นมาเองไม่ได้ ทริกคือ **แอบใส่เลข $1$ ไว้ในสถานะ** ให้เมทริกซ์หยิบไปคูณกับค่าคงที่ได้ และเพิ่มแถวที่ทำให้เลข $1$ ยังเป็น $1$ ทุกก้าว

ลองกับเพื่อนเก่าจากบท Binary Exponentiation: $S_n = 1 + a + a^2 + \cdots + a^n$ เขียนเป็น recurrence ได้ว่า $S_n = a \cdot S_{n-1} + 1$ โดย $S_0 = 1$ ใช้สถานะ $(S_n, 1)$

$$\begin{pmatrix} S_n \\ 1 \end{pmatrix} = \begin{pmatrix} a & 1 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} S_{n-1} \\ 1 \end{pmatrix}$$

```cpp
long long geometric(long long a, long long n) {
  Matrix m = {{a % MOD, 1},
              {0, 1}};                     // แถวล่างทำให้เลข 1 ยังเป็น 1
  return mulVec(matPow(m, n), {1, 1})[0];  // เริ่มจาก (S_0, 1) = (1, 1)
}
```

ไม่ต้องหารเลย จึงใช้ได้กับ mod ใด ๆ ด้วย ท่าเดียวกันนี้ขยายได้อีก เช่น $f_n = f_{n-1} + n$ ก็ใช้สถานะ $(f_n, n, 1)$ เพราะ $n$ เองก็เดินด้วยกฎ $n = (n - 1) + 1$ ที่เป็นเชิงเส้น

## มองเป็นกราฟ: นับ walk ยาว L

นี่คือมุมมองที่ทรงพลังที่สุดของบทนี้ ให้ $A$ เป็น adjacency matrix ของกราฟมีทิศทาง โดย $A_{uv}$ คือ **จำนวนเส้นเชื่อม** จาก $u$ ไป $v$ (มีเส้นซ้ำก็นับซ้ำ) แล้วช่อง $\left(A^L\right)_{uv}$ คือ **จำนวน walk ยาว $L$ จาก $u$ ไป $v$** พอดี

**walk** คือการเดินตามเส้นเชื่อม $L$ เส้นต่อกัน จะผ่านจุดหรือเส้นเดิมซ้ำกี่รอบก็ได้ ทำไมถึงจริง? ดูช่อง $(u, v)$ ของ $A^2$

$$\left(A^2\right)_{uv} = \sum_{w} A_{uw} \cdot A_{wv}$$

ผลรวมนี้ไล่จุดกลางทาง $w$ ทุกจุด จำนวนวิธีเดิน $u \to w$ หนึ่งก้าว คูณจำนวนวิธีเดิน $w \to v$ หนึ่งก้าว ก็คือจำนวน walk ยาว $2$ ที่แวะ $w$ บวกครบทุก $w$ ก็ได้จำนวน walk ยาว $2$ ทั้งหมด แล้วใช้เหตุผลเดิมซ้ำ: $A^{L} = A^{L-1} \cdot A$ คือ "walk ยาว $L - 1$ แล้วต่ออีกหนึ่งเส้น"

ลองกับกราฟเล็ก ๆ นี้ (จุด $3$ มีเส้นวนกลับเข้าตัวเอง)

```text
  1 <---> 2 ---> 3 --+
                 ^   |
                 +---+
```

$$A = \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 0 & 1 \end{pmatrix} \qquad A^2 = \begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 1 \\ 0 & 0 & 1 \end{pmatrix} \qquad A^3 = \begin{pmatrix} 0 & 1 & 1 \\ 1 & 0 & 2 \\ 0 & 0 & 1 \end{pmatrix}$$

$\left(A^3\right)_{23} = 2$ ตรงกับ walk ยาว $3$ จาก $2$ ไป $3$ ที่มีสองแบบจริง ๆ คือ $2 \to 1 \to 2 \to 3$ และ $2 \to 3 \to 3 \to 3$ ส่วน $\left(A^3\right)_{11} = 0$ เพราะจาก $1$ ต้องเดินเป็นคู่ไปกลับ $1 \to 2 \to 1$ หรือหลุดไปติดที่ $3$ ซึ่งกลับมาไม่ได้

ถ้าย้อนกลับไปดู Fibonacci ก็คือเรื่องเดียวกัน: $M$ เป็น adjacency matrix ของกราฟสองจุด มองแบบนี้แล้วโจทย์นับวิธีหลายข้อจะกลายเป็น "สร้างกราฟของสถานะ แล้วนับ walk" ทันที

### อยากได้แถวเดียว ไม่ต้องคูณทั้งเมทริกซ์

ถ้าถามแค่ walk ที่เริ่มจาก $s$ เราสนใจแค่แถว $s$ ของ $A^L$ ซึ่งคือเวกเตอร์แถว $e_s$ (มีเลข $1$ ที่ช่อง $s$) คูณ $A^L$ การคูณ **เวกเตอร์กับเมทริกซ์** ใช้แค่ $O(k^2)$ ไม่ใช่ $O(k^3)$ และเพราะ $A^L$ เป็นผลคูณของ $A^{2^i}$ ตามบิตของ $L$ เราจึงเอาเวกเตอร์ไปคูณกับ $A^{2^i}$ ทีละตัวได้เลยโดยไม่ต้องรวมเป็น $A^L$ ก่อน (เหมือน `mulVec` ใน template แค่สลับข้างเป็นเวกเตอร์แถวคูณจากซ้าย) แต่ $A^{2^i}$ แต่ละตัวยังต้องได้มาจากการยกกำลังสองแบบเต็ม ๆ อยู่ดี

:::problem lp_mat02_patrol_routes

:::hint ใบ้ Patrol Routes
นับ walk ตรง ๆ ด้วย $A^L$ ได้เลย แต่ลองนับต้นทุนก่อน: ยกกำลังเมทริกซ์ $50 \times 50$ หนึ่งครั้งใช้ราว $120$ การคูณ คูณละ $50^3$ ทำใหม่ทุกคำถาม $100$ ข้อเกิน $10^9$ แน่นอน สังเกตว่าทุกคำถามใช้กราฟเดียวกัน ส่วนไหนของงานที่ทำ**ครั้งเดียว**แล้วแชร์ให้ทุกคำถามได้? แล้วส่วนที่เหลือต่อคำถามจะลดเหลือการคูณแบบไหน?
:::

## ความซับซ้อน

ยกกำลังเมทริกซ์ $k \times k$ หนึ่งครั้งใช้ไม่เกิน $2 \log_2 N$ การคูณ คูณละ $O(k^3)$ รวมเป็น $O(k^3 \log N)$

| $k$ | $N$ | ราว ๆ |
|---|---|---|
| $2$ (Fibonacci) | $10^{18}$ | $120 \times 8 \approx 10^3$ |
| $50$ | $10^{18}$ | $120 \times 125{,}000 = 1.5 \times 10^7$ |
| $100$ | $10^{18}$ | $1.2 \times 10^8$ (เริ่มหนัก) |

ข้อสังเกตสองอย่าง หนึ่ง $N$ แทบไม่มีผล ($\log_2 10^{18} \approx 60$) ตัวที่ฆ่าเราคือ $k^3$ ดังนั้นเวลาออกแบบสถานะให้ **เล็กที่สุดเท่าที่จะทำได้** สอง ถ้าต้องยกกำลังหลายครั้ง ต้นทุนก็คูณจำนวนครั้งเข้าไปด้วย เทียบกับลูปธรรมดา $O(N \cdot k)$ ที่ทนได้แค่ $N$ ราว $10^7$ ถึง $10^8$ ถ้าโจทย์ให้ $N$ ใหญ่ถึง $10^{18}$ แต่สถานะเล็ก นั่นคือสัญญาณของ matrix exponentiation

:::note สำหรับคนเขียน Python
ลูปสามชั้นของ Python ช้ากว่า C++ หลายสิบเท่า $k = 3$ สบายมาก แต่ $k = 50$ ควรคำนวณผลคูณแต่ละช่องด้วย `sum(map(operator.mul, row, col))` (เตรียมคอลัมน์ไว้ก่อนด้วย `list(zip(*b))`) ให้ลูปในสุดไปวิ่งในภาษา C และจำนวนเต็มของ Python ไม่ล้น จะ mod ทีเดียวหลังรวมครบทั้งแถวก็ได้
:::

:::warning จุดที่พลาดบ่อย
* **บวกผลคูณหลายคู่ก่อน mod** ด้วย `long long` แล้วล้น บน judge นี้ได้ Runtime Error ทันที ให้ mod หลังบวกทุกครั้ง
* **เลขชี้กำลังเพี้ยนไปหนึ่ง** $M^{N}$ หรือ $M^{N-1}$ ขึ้นกับว่าสถานะเริ่มต้นมีพจน์ไหน ทดสอบกับลูปธรรมดาตอน $N$ เล็ก ๆ ทุกครั้ง และอย่าลืม $N = 0$ ที่ยกกำลังได้ $I$
* **สร้างเมทริกซ์กลับด้าน** (สลับแถวกับคอลัมน์) ถ้าคูณเวกเตอร์หลักจากขวา แถว $i$ ของ $M$ คือ "สูตรของช่อง $i$ ในสถานะใหม่" ถ้าคูณเวกเตอร์แถวจากซ้าย ก็ต้องใช้ $M$ ที่ transpose แล้ว เลือกแบบเดียวแล้วใช้ให้ตลอด
* **ลืมแถวที่ทำให้เลข $1$ ยังเป็น $1$** ตอนเติมค่าคงที่ ช่องนั้นจะกลายเป็น $0$ หลังก้าวแรก
* **สัมประสิทธิ์ติดลบ** ใส่ลงเมทริกซ์ตรง ๆ แล้ว `%` ได้เศษติดลบ ให้แปลงเป็น $c + (10^9 + 7)$ ก่อน
* **ตั้งชื่อฟังก์ชัน `identity` หรือ `apply`** ใน C++20 ชื่อนี้ชนกับ `std::identity` และ `std::apply` เมื่อมี `using namespace std;` คอมไพล์ไม่ผ่านด้วย "reference is ambiguous" template จึงใช้ `unit` กับ `mulVec`
* **เริ่ม `result` เป็นเมทริกซ์ศูนย์** แทนเมทริกซ์เอกลักษณ์ คำตอบจะเป็น $0$ หมด
* **ยกกำลังใหม่ทุกคำถาม** ทั้งที่เมทริกซ์ไม่เปลี่ยน ต้นทุน $O(k^3 \log N)$ จะคูณจำนวนคำถามเข้าไปด้วย
:::

## สรุปสั้น ๆ

* recurrence เชิงเส้น $f_n = c_1 f_{n-1} + \cdots + c_k f_{n-k}$ เขียนเป็น "สถานะใหม่ $= M \cdot$ สถานะเก่า" ได้เสมอ แถวแรกของ $M$ คือสัมประสิทธิ์ แถวที่เหลือเลื่อนค่าเดิมลง
* การคูณเมทริกซ์เปลี่ยนกลุ่มได้ จึงหา $M^N$ ด้วย binary exponentiation ใน $O(k^3 \log N)$ เริ่มจากเมทริกซ์เอกลักษณ์
* มีค่าคงที่หรือพจน์อย่าง $n$ ให้เพิ่มเลข $1$ (หรือ $n$) เข้าไปในสถานะ
* $\left(A^L\right)_{uv}$ คือจำนวน walk ยาว $L$ จาก $u$ ไป $v$ เมื่อ $A_{uv}$ คือจำนวนเส้นเชื่อม
* ทุกช่องอยู่ใน $[0, 10^9 + 7)$ และ mod หลังบวกทุกผลคูณ ไม่งั้น `long long` ล้น
* ต้องการแค่แถวเดียวหรือเวกเตอร์เดียว ใช้การคูณเวกเตอร์กับเมทริกซ์ $O(k^2)$ ได้
