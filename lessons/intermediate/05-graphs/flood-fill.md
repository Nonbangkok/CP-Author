## ตารางก็คือกราฟ

แผนที่เกาะ, เขาวงกต, ภาพพิกเซล, ไร่นา โจทย์พวกนี้ให้ข้อมูลมาเป็น **ตาราง (grid)** $R$ แถว $C$ คอลัมน์ ไม่มีรายการเส้นเชื่อมให้เลย แต่จริง ๆ แล้วมันคือกราฟที่ซ่อนอยู่ (**implicit graph**)

* **จุดยอด** คือช่อง $(r, c)$ แต่ละช่อง
* **เส้นเชื่อม** คือช่องที่ติดกัน (และเดินถึงกันได้ตามกติกาของโจทย์ เช่นไม่ใช่กำแพง)

ข่าวดีคือเราไม่ต้องสร้าง `adj` เลย เพราะคำนวณเพื่อนบ้านของช่องไหนก็ได้ทันที ทุกอย่างจากบท Graphs, BFS and DFS ใช้ได้หมด แค่เปลี่ยน "ไล่ `adj[u]`" เป็น "ไล่ช่องข้าง ๆ" การระบายทั้งก้อนที่ติดกันแบบนี้มีชื่อเฉพาะว่า **flood fill** (เหมือนเครื่องมือถังสีในโปรแกรมวาดรูป)

## เพื่อนบ้านด้วย `dr` / `dc`

แทนที่จะเขียน `if` สี่ครั้ง ให้เก็บทิศไว้ในอาเรย์แล้ววนลูป

```text
       (r-1, c)                 (r-1,c-1) (r-1,c) (r-1,c+1)
(r, c-1) (r, c) (r, c+1)        (r, c-1)  (r, c)  (r, c+1)
       (r+1, c)                 (r+1,c-1) (r+1,c) (r+1,c+1)

     4 ทิศ: บน ล่าง ซ้าย ขวา       8 ทิศ: เพิ่มแนวทแยงอีก 4
```

```cpp
const int dr[4] = {-1, 1, 0, 0};
const int dc[4] = {0, 0, -1, 1};
// 8 ทิศ:
// const int dr[8] = {-1, -1, -1, 0, 0, 1, 1, 1};
// const int dc[8] = {-1, 0, 1, -1, 1, -1, 0, 1};

for (int d = 0; d < 4; d++) {
  int nr = r + dr[d], nc = c + dc[d];
  if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;   // เช็กขอบก่อนเสมอ
  // ... ใช้ g[nr][nc] ได้อย่างปลอดภัย
}
```

โจทย์จะบอกเองว่านับแนวทแยงหรือไม่ อ่านดี ๆ เพราะคำตอบต่างกันได้มาก เช่น `#` สองช่องที่แตะกันแค่ที่มุม เป็นเกาะเดียวกันใน 8 ทิศ แต่เป็นสองเกาะใน 4 ทิศ

**การเช็กขอบต้องมาก่อน** การอ่าน `g[nr][nc]` เสมอ ถ้าสลับลำดับ ช่องนอกตารางจะถูกอ่านก่อนรู้ว่ามันอยู่นอกตาราง

## Flood fill: นับเกาะและขนาดของแต่ละเกาะ

โจทย์ตัวอย่าง: `#` คือแผ่นดิน `.` คือน้ำ เกาะคือแผ่นดินที่ติดกันใน 4 ทิศ ให้นับเกาะ และบอกพื้นที่ของทุกเกาะเรียงจากใหญ่ไปเล็ก

ท่าเดียวกับนับ component เป๊ะ: ไล่ทุกช่อง เจอแผ่นดินที่ยังไม่เคยไปก็คือเกาะใหม่ แล้ว BFS ระบายทั้งเกาะ เทคนิคเล็ก ๆ ที่ใช้บ่อยคือ **mark ลงในตารางเลย** เปลี่ยน `#` เป็น `.` ตอนใส่ลง queue ไม่ต้องมีอาเรย์ `seen` แยก (ใช้ได้เมื่อไม่ต้องใช้ตารางเดิมอีก)

### Template: นับเกาะ + พื้นที่ของแต่ละเกาะ

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  int R, C;
  cin >> R >> C;
  vector<string> g(R);
  for (auto &row : g) cin >> row;
  const int dr[4] = {-1, 1, 0, 0};
  const int dc[4] = {0, 0, -1, 1};

  vector<int> areas;
  for (int sr = 0; sr < R; sr++) {
    for (int sc = 0; sc < C; sc++) {
      if (g[sr][sc] != '#') continue;      // ไม่ใช่แผ่นดิน หรือระบายไปแล้ว
      int area = 0;
      queue<pair<int, int>> q;
      g[sr][sc] = '.';                       // mark ตอนใส่ลง queue
      q.push({sr, sc});
      while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        area++;
        for (int d = 0; d < 4; d++) {
          int nr = r + dr[d], nc = c + dc[d];
          if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
          if (g[nr][nc] != '#') continue;
          g[nr][nc] = '.';
          q.push({nr, nc});
        }
      }
      areas.push_back(area);
    }
  }
  sort(areas.rbegin(), areas.rend());
  cout << areas.size() << '\n';
  for (int a : areas) cout << a << ' ';
  cout << '\n';
}
```

### ลองไล่ด้วยมือ

```text
5 6               นับแถว/คอลัมน์จาก 0
##..#.            เกาะ A: (0,0) (0,1) (1,0)                  พื้นที่ 3
#...##            เกาะ B: (0,4) (1,4) (1,5)                  พื้นที่ 3
..#...            เกาะ C: (2,2) (3,1) (3,2) (3,3)            พื้นที่ 4
.###..            เกาะ D: (4,4) (4,5)                        พื้นที่ 2
....##
```

ไล่แถวบนลงล่าง ซ้ายไปขวา เจอ `#` ตัวแรกที่ $(0, 0)$ ก็ BFS ระบายเกาะ A ทั้งเกาะกลายเป็น `.` จากนั้นลูปเดินต่อไปเจอ $(0, 4)$ เป็นเกาะ B ต่อด้วย $(2, 2)$ ซึ่งพาไปถึง $(3, 1)$, $(3, 2)$, $(3, 3)$ เป็นเกาะ C และสุดท้าย $(4, 4)$ เป็นเกาะ D โปรแกรมพิมพ์ `4` แล้วตามด้วย `4 3 3 2`

ช่อง $(1, 5)$ ติดกับ $(2, 5)$ ไหม? $(2, 5)$ เป็นน้ำ จึงไม่เกี่ยว และ $(3, 3)$ กับ $(4, 4)$ แตะกันแค่ที่มุม ใน 4 ทิศจึงเป็นคนละเกาะ

:::problem lp_ff01_crop_regions

:::hint ใบ้ Crop Regions
คราวนี้ทุกช่องอยู่ในแปลงใดแปลงหนึ่ง และเงื่อนไขของเพื่อนบ้านเปลี่ยนจาก "เป็น `#`" เป็น "ปลูกพืชตัวอักษรเดียวกับช่องที่เริ่ม" เพราะต้องใช้ตัวอักษรเดิมเทียบตลอด จะ mark ทับลงตารางตรง ๆ ไม่ได้แล้ว ใช้ `vector<char> seen` แยกไว้ ตารางใหญ่ได้ถึง $10^6$ ช่อง อย่าใช้ recursion
:::

## ระยะทางที่สั้นที่สุดบนตาราง

คำถามแบบ "เดินจากช่องนี้ไปช่องนั้นน้อยที่สุดกี่ก้าว" คือ shortest path บนกราฟที่ทุกเส้นยาวเท่ากัน คำตอบก็คือ BFS เหมือนบทที่แล้ว ต่างกันแค่ `dist` เป็นตาราง

### Template: ระยะจาก `S` ไปทุกช่อง

ตัวอย่างนี้ถามว่าจาก `S` ไปถึงได้กี่ช่อง และช่องที่ไกลที่สุดที่ไปถึงอยู่ห่างกี่ก้าว

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  int R, C;
  cin >> R >> C;
  vector<string> g(R);
  for (auto &row : g) cin >> row;
  const int dr[4] = {-1, 1, 0, 0};
  const int dc[4] = {0, 0, -1, 1};

  vector<vector<int>> dist(R, vector<int>(C, -1));   // -1 = ยังไปไม่ถึง
  queue<pair<int, int>> q;
  for (int r = 0; r < R; r++)
    for (int c = 0; c < C; c++)
      if (g[r][c] == 'S') {
        dist[r][c] = 0;
        q.push({r, c});
      }

  int reached = 0, farthest = 0;
  while (!q.empty()) {
    auto [r, c] = q.front();
    q.pop();
    reached++;
    farthest = max(farthest, dist[r][c]);
    for (int d = 0; d < 4; d++) {
      int nr = r + dr[d], nc = c + dc[d];
      if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
      if (g[nr][nc] == '#' || dist[nr][nc] != -1) continue;
      dist[nr][nc] = dist[r][c] + 1;
      q.push({nr, nc});
    }
  }
  cout << reached << ' ' << farthest << '\n';
}
```

กับตาราง

```text
4 5
S..#.
.#.#.
.#...
...#.
```

ช่องที่เดินถึงได้มีทั้งหมด $15$ ช่อง (ทุกช่องที่ไม่ใช่ `#`) ช่องที่ไกลที่สุดคือมุมขวาบน $(0, 4)$ ห่าง $8$ ก้าว: ต้องอ้อมลงไปแถว $2$ ก่อนเพราะคอลัมน์ $3$ มีกำแพงขวางอยู่ โปรแกรมพิมพ์ `15 8`

:::problem lp_ff02_maze_runner

:::hint ใบ้ Maze Runner
ใช้ template นี้แทบทั้งก้อน แค่ตอนจบให้ดู `dist` ของช่อง `E` ถ้ายังเป็น $-1$ ก็ไปไม่ถึง (`E` ไม่ใช่กำแพง เดินเข้าไปได้ตามปกติ) ถ้าอยากเร็วขึ้นอีกนิดจะหยุด BFS ทันทีที่เจอ `E` ก็ได้
:::

## Multi-source BFS: หลายจุดเริ่มพร้อมกัน

บางโจทย์มีจุดเริ่ม **หลายจุด** เช่น "น้ำไหลออกจากทุกบ่อพร้อมกัน แต่ละนาทีลามไปช่องข้าง ๆ อีกหนึ่งช่อง กี่นาทีทุกช่องถึงจะเปียก" หรือ "แต่ละช่องอยู่ห่างทางออกที่ใกล้ที่สุดกี่ก้าว"

ท่าตรง ๆ คือ BFS จากทุกบ่อทีละบ่อแล้วเอาค่าน้อยสุด ถ้ามี $K$ บ่อก็เป็น $O(K \cdot RC)$ ซึ่งช้ามาก ท่าที่ถูกคือ **ใส่ทุกจุดเริ่มลง queue ตั้งแต่แรก ด้วยระยะ $0$** แล้ว BFS ตามปกติรอบเดียว

ทำไมถึงถูก? ลองนึกว่ามี "จุดเริ่มปลอม" หนึ่งจุดที่ต่อเส้นไปทุกบ่อ BFS จากจุดปลอมนั้น ชั้นแรกก็คือทุกบ่อพร้อมกันนั่นเอง ระยะที่ได้ของแต่ละช่องจึงเป็นระยะถึง **บ่อที่ใกล้ที่สุด** อัตโนมัติ งานรวมเหลือ $O(RC)$

```text
ตาราง           นาทีที่ช่องเปียก
W....           0 1 2 3 2
.###.           1 # # # 1
....W           2 3 2 1 0
```

### Template: กี่นาทีทุกช่องจะเปียก

`W` คือบ่อน้ำ, `.` คือดินแห้ง, `#` คือหินที่น้ำผ่านไม่ได้ ให้ตอบนาทีที่ดินแห้งช่องสุดท้ายเปียก หรือ $-1$ ถ้ามีช่องที่น้ำไปไม่ถึงเลย

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  int R, C;
  cin >> R >> C;
  vector<string> g(R);
  for (auto &row : g) cin >> row;
  const int dr[4] = {-1, 1, 0, 0};
  const int dc[4] = {0, 0, -1, 1};

  vector<vector<int>> t(R, vector<int>(C, -1));
  queue<pair<int, int>> q;
  for (int r = 0; r < R; r++)
    for (int c = 0; c < C; c++)
      if (g[r][c] == 'W') {           // ทุกบ่อเข้า queue ตั้งแต่แรก นาทีที่ 0
        t[r][c] = 0;
        q.push({r, c});
      }

  while (!q.empty()) {
    auto [r, c] = q.front();
    q.pop();
    for (int d = 0; d < 4; d++) {
      int nr = r + dr[d], nc = c + dc[d];
      if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
      if (g[nr][nc] != '.' || t[nr][nc] != -1) continue;
      t[nr][nc] = t[r][c] + 1;
      q.push({nr, nc});
    }
  }

  int answer = 0;
  for (int r = 0; r < R; r++)
    for (int c = 0; c < C; c++)
      if (g[r][c] == '.') {
        if (t[r][c] == -1) answer = -1;              // มีช่องที่ไม่มีวันเปียก
        else if (answer != -1) answer = max(answer, t[r][c]);
      }
  cout << answer << '\n';
}
```

### ลองไล่ด้วยมือ

ใช้ตารางในรูปข้างบน (input `3 5` ตามด้วยสามแถวนั้น) queue เริ่มด้วยบ่อ $(0, 0)$ และ $(2, 4)$ พร้อมกัน

| นาที | ช่องที่เพิ่งเปียก |
|---|---|
| 0 | $(0,0)$, $(2,4)$ |
| 1 | $(0,1)$, $(1,0)$, $(1,4)$, $(2,3)$ |
| 2 | $(0,2)$, $(2,0)$, $(0,4)$, $(2,2)$ |
| 3 | $(0,3)$, $(2,1)$ |

ช่อง $(0, 4)$ เปียกในนาทีที่ $2$ จากบ่อขวาล่าง (ผ่าน $(1, 4)$) ไม่ใช่นาทีที่ $4$ จากบ่อซ้ายบน เพราะ BFS แจกระยะให้จากบ่อที่ใกล้กว่าก่อนเสมอ ส่วน $(0, 3)$ กับ $(2, 1)$ น้ำจากทั้งสองบ่อมาถึงในนาทีที่ $3$ พร้อมกัน ใครใส่ก่อนก็ได้ค่าเดียวกัน โปรแกรมพิมพ์ `3` ถ้าเปลี่ยน `W` ตัวขวาล่างเป็น `.` คำตอบจะกลายเป็น $6$ และถ้าเอาหินล้อม `.` สักช่องไว้ คำตอบจะเป็น $-1$

:::problem lp_ff03_fire_escape

:::hint ใบ้ Fire Escape
มีสองสิ่งที่เคลื่อนที่: ไฟ (หลายจุดเริ่ม และไม่สนใจน้องเจเลย) กับน้องเจ (จุดเริ่มเดียว แต่ต้องหลบไฟ) เริ่มจาก multi-source BFS ของไฟก่อน ได้นาทีที่แต่ละช่องเริ่มไหม้ จากนั้น BFS ของน้องเจ แต่จะก้าวเข้าช่องไหนในนาทีที่ $t$ ได้ ต้องเช็กกับนาทีที่ไฟมาถึงช่องนั้นด้วย อ่านโจทย์ให้ดีว่าถ้ามาถึงพร้อมกันแปลว่าอะไร และช่องที่ไฟไปไม่ถึงเลยก็ต้องเดินได้ (ระวังค่าเริ่มต้นของ `fire`) การหนีสำเร็จคือการก้าวจากช่องริมขอบออกไป ซึ่งใช้อีกหนึ่งนาที
:::

## ความซับซ้อน

ทุกช่องเข้า queue ได้ไม่เกินหนึ่งครั้ง และแต่ละครั้งมองเพื่อนบ้าน 4 (หรือ 8) ช่อง รวมเป็น $O(RC)$ ทั้ง flood fill นับเกาะ, BFS หาระยะ และ multi-source BFS ตาราง $1{,}000 \times 1{,}000$ คือ $10^6$ ช่อง สบาย ๆ ภายในเวลา

ส่วนหน่วยความจำ `vector<vector<int>>` ขนาด $10^6$ ช่องใช้ราว 4 MB ไม่มีปัญหา แต่ **อย่าประกาศอาเรย์ใหญ่ ๆ เป็นตัวแปรภายในฟังก์ชัน** เช่น `int dist[1000][1000];` ใน `main` เพราะมันจะไปอยู่บน stack (ราว 8 MB) ใช้ `vector` หรือประกาศเป็นตัวแปร global แทน

## จุดที่พลาดบ่อย

:::warning flood fill แบบ recursive บนตารางใหญ่
`void fill(int r, int c)` ที่เรียกตัวเองสี่ทิศ เขียนง่ายมาก แต่ตารางที่เป็นทางคดเคี้ยวยาว ๆ ทำให้ recursion ลึกได้ถึงจำนวนช่องทั้งหมด ($10^6$) ซึ่งทำ stack ล้นแน่นอน บนตารางใหญ่ให้ใช้ BFS ด้วย queue หรือ stack ของเราเองเสมอ
:::

:::warning สลับแถวกับคอลัมน์
บรรทัดแรกมักเป็น $R$ (จำนวนแถว) ก่อน $C$ (จำนวนคอลัมน์) และ `g[r][c]` คือแถว `r` คอลัมน์ `c` เวลาตารางไม่เป็นสี่เหลี่ยมจัตุรัส ถ้าสลับกันจะอ่านนอกขอบทันที ทดสอบกับตาราง $1 \times C$ และ $R \times 1$ ทุกครั้ง
:::

:::warning mark ตอนใส่ลง queue
เหมือนบทที่แล้ว: ตั้ง `dist` หรือ mark ช่อง **ตอนใส่** ไม่ใช่ตอนหยิบ บนตาราง ช่องหนึ่งมีเพื่อนบ้านได้ถึง 4 ช่อง ถ้า mark ช้าช่องเดียวกันจะถูกใส่ซ้ำสูงสุด 4 เท่า
:::

ถ้าใส่บ่อแรกแล้ว BFS จนจบ ค่อยใส่บ่อที่สอง ระยะที่ได้จะเป็นระยะจากบ่อแรกเกือบทั้งหมด ซึ่งผิด ทุกจุดเริ่มต้องอยู่ใน queue ด้วยระยะ $0$ **ก่อน** หยิบตัวแรกออก
:::

:::note เทคนิคขอบกำแพง
อีกท่าที่ทำให้ไม่ต้องเช็กขอบ: สร้างตารางขนาด $(R + 2) \times (C + 2)$ ที่มีกำแพงล้อมรอบ แล้ววางตารางจริงไว้ตรงกลาง เพื่อนบ้านของช่องจริงทุกช่องจะอยู่ในตารางเสมอ ได้โค้ดสั้นลงและเร็วขึ้นเล็กน้อย เหมาะมากกับ Python
:::

## สรุปสั้น ๆ

* ตารางคือกราฟที่ไม่ต้องสร้าง `adj`: ช่องคือจุดยอด ช่องที่ติดกันคือเส้นเชื่อม
* ใช้ `dr` / `dc` วนเพื่อนบ้าน 4 หรือ 8 ทิศตามโจทย์ และเช็กขอบก่อนอ่านตารางเสมอ
* Flood fill = ไล่ทุกช่อง เจอช่องใหม่ก็ BFS ระบายทั้งก้อน ได้ทั้งจำนวนก้อนและขนาด
* BFS บนตารางให้จำนวนก้าวที่น้อยที่สุด เก็บ `dist` เป็นตาราง เริ่มที่ $-1$
* Multi-source BFS: ใส่ทุกจุดเริ่มด้วยระยะ $0$ ก่อน แล้ว BFS รอบเดียว ได้ระยะถึงจุดเริ่มที่ใกล้ที่สุด
* ทุกอย่างเป็น $O(RC)$ ใช้ queue แทน recursion และใช้ `vector` แทนอาเรย์ใหญ่ใน `main`
