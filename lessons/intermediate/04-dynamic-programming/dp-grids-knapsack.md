## จาก 1D ไป 2D

บทที่แล้ว state เป็นตัวเลขตัวเดียว `dp[i]` แต่หลายโจทย์ต้องใช้ **สองตัวเลข** ถึงจะบอกได้ว่าเรา "อยู่ตรงไหน" ของปัญหา เช่น ตำแหน่งในตาราง (แถว, คอลัมน์), ตำแหน่งในสตริงสองเส้น หรือ (ของชิ้นที่เท่าไร, ความจุที่เหลือ) สี่คำถามเดิมยังใช้ได้ทุกข้อ: state แปลว่าอะไร, transition มาจากไหน, base case และ **ลำดับการเติมตาราง** ซึ่งในสองมิติต้องคิดให้ดีขึ้นอีกนิด

## เส้นทางในตาราง

ตาราง $R \times C$ ช่องว่างเป็น `.` ช่องหินเป็น `#` เริ่มที่มุมซ้ายบน เดินได้แค่ **ขวา** หรือ **ลง** มีกี่เส้นทางที่ไปถึงมุมขวาล่าง

* State: `ways[r][c]` = จำนวนเส้นทางจากจุดเริ่มถึงช่อง $(r, c)$
* Transition: ก้าวสุดท้ายมาจาก **ช่องบน** หรือ **ช่องซ้าย** เท่านั้น: `ways[r][c] = ways[r-1][c] + ways[r][c-1]` และช่องหินเป็น $0$
* Base case: `ways[0][0] = 1` (ถ้าไม่ใช่หิน)
* ลำดับ: ทีละแถวจากบนลงล่าง ในแถวเดียวกันจากซ้ายไปขวา ตอนเติม $(r, c)$ ช่องบนกับช่องซ้ายเติมไว้แล้วแน่นอน

```text
            ways[r-1][c]
                 |
                 v
ways[r][c-1] -> ways[r][c]
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1'000'000'007;

int main() {
  int rows, cols;
  cin >> rows >> cols;
  vector<string> g(rows);
  for (auto &line : g) cin >> line;
  vector<vector<long long>> ways(rows, vector<long long>(cols, 0));
  for (int r = 0; r < rows; r++)
    for (int c = 0; c < cols; c++) {
      if (g[r][c] == '#') continue;                    // หิน: 0 เส้นทาง
      if (r == 0 && c == 0) { ways[r][c] = 1; continue; }
      long long total = 0;
      if (r > 0) total += ways[r - 1][c];               // มาจากข้างบน
      if (c > 0) total += ways[r][c - 1];               // มาจากข้างซ้าย
      ways[r][c] = total % MOD;
    }
  cout << ways[rows - 1][cols - 1] << '\n';
}
```

ไล่มือกับตาราง $3 \times 4$ ที่มีหินหนึ่งก้อน

```text
ตาราง        ways
. . . .      1  1  1  1
. # . .      1  0  1  2
. . . .      1  1  2  4
```

ช่องในแถวบนสุดกับคอลัมน์ซ้ายสุดมีทางเดียว (เดินตรงมาอย่างเดียว) ช่องหินเป็น $0$ เลยไม่ส่งต่อเส้นทางให้ใคร คำตอบคือ $4$ ตรวจกลับได้: ถ้าไม่มีหินมี $\binom{5}{2} = 10$ เส้นทาง ผ่านช่องหิน $2 \times 3 = 6$ เส้นทาง เหลือ $4$

**ค่าใช้จ่ายน้อยที่สุด** ก็โครงเดียวกัน ถ้าทุกช่องมีค่าผ่าน $a_{r,c}$ แล้วอยากได้เส้นทางที่ถูกที่สุด ให้เปลี่ยนบวกเป็น `a[r][c] + min(บน, ซ้าย)` แต่ระวังช่องที่ "ไปไม่ถึง" (โดนหินล้อม) ต้องแทนด้วยค่าพิเศษ เช่น INF แล้วห้ามเอา INF ไปบวกต่อ ไม่อย่างนั้นจะล้นหรือได้คำตอบมั่ว

:::problem lp_dpk01_gold_path

:::hint ใบ้ Gold Path
เหมือนค่าใช้จ่ายน้อยที่สุด แต่กลับเป็น **max** ให้ `dp[r][c]` = ทองมากสุดที่เก็บได้จนถึงช่อง $(r, c)$ แล้วต้องมีค่าพิเศษแทน "ไปไม่ถึง" ซึ่งต่างจากช่องที่มีทอง $0$ ก้อน (ทองไม่ติดลบ จึงใช้ $-1$ ได้) ช่องที่ไปไม่ถึงต้องไม่ส่งค่าต่อให้ช่องถัดไป และอย่าลืมกรณีที่ช่องเริ่มต้นเป็นหิน
:::

## DP บนสตริงสองเส้น: LCS

**Longest Common Subsequence**: ให้สตริง $A$ ยาว $n$ และ $B$ ยาว $m$ หา subsequence ที่ยาวที่สุดที่เป็นของทั้งคู่ เช่น `acbd` กับ `abcd` มี `abd` และ `acd` ยาว $3$

ท่าคิดของ DP บนสองสตริงที่ใช้ได้แทบทุกข้อคือให้ state เป็น **คำนำหน้า (prefix) ของทั้งสองเส้น**

* State: `dp[i][j]` = ความยาว LCS ของ $A$ ตัวแรก $i$ ตัว กับ $B$ ตัวแรก $j$ ตัว
* Transition: ดูแค่ **ตัวสุดท้าย** ของสอง prefix คือ `A[i-1]` กับ `B[j-1]`
  * ถ้าเท่ากัน จับคู่สองตัวนี้ได้เลย: `dp[i-1][j-1] + 1`
  * ถ้าไม่เท่า อย่างน้อยหนึ่งตัวไม่อยู่ในคำตอบ ทิ้งตัวใดตัวหนึ่ง: `max(dp[i-1][j], dp[i][j-1])`
* Base case: `dp[0][j] = dp[i][0] = 0` (prefix ว่างไม่มีอะไรร่วมกัน)

```text
dp[i-1][j-1]   dp[i-1][j]          ทิแยง: A[i-1] == B[j-1] จับคู่ +1
          \       |                 บน:    ทิ้ง A[i-1]
           \      v                 ซ้าย:  ทิ้ง B[j-1]
dp[i][j-1] -> dp[i][j]
```

Template นี้หาความยาวแล้ว **ย้อนรอย** ออกมาเป็นสตริงด้วย: เริ่มที่ $(n, m)$ ถ้าตัวท้ายเท่ากันก็เก็บตัวนั้นแล้วไปทิแยง ไม่อย่างนั้นไปทางที่ค่ามากกว่า (ทางที่ค่านั้นมาจริง)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  string a, b;
  cin >> a >> b;
  int n = a.size(), m = b.size();
  vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
  for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
      if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
      else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);

  string lcs;                                  // ย้อนจาก (n, m) กลับไป (0, 0)
  int i = n, j = m;
  while (i > 0 && j > 0) {
    if (a[i - 1] == b[j - 1]) { lcs += a[i - 1]; i--; j--; }
    else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
    else j--;
  }
  reverse(lcs.begin(), lcs.end());             // เก็บมาจากท้าย ต้องกลับด้าน
  cout << dp[n][m] << '\n' << lcs << '\n';
}
```

ไล่มือกับ $A$ = `acbd`, $B$ = `abcd` (แถวคือ $i$, คอลัมน์คือ $j$)

| | `""` | `a` | `b` | `c` | `d` |
|---|---|---|---|---|---|
| `""` | 0 | 0 | 0 | 0 | 0 |
| `a` | 0 | **1** | 1 | 1 | 1 |
| `c` | 0 | 1 | 1 | **2** | 2 |
| `b` | 0 | 1 | 2 | 2 | 2 |
| `d` | 0 | 1 | 2 | 2 | **3** |

ย้อนรอยจาก $(4, 4)$: `d = d` เก็บ `d` ไป $(3, 3)$; `b ≠ c` ค่าบนกับซ้ายเท่ากัน ($2$) ขึ้นบนไป $(2, 3)$; `c = c` เก็บ `c` ไป $(1, 2)$; `a ≠ b` ซ้ายมากกว่า ไป $(1, 1)$; `a = a` เก็บ `a` ได้ `acd` (ตัวหนาในตาราง) โปรแกรมพิมพ์ `3` กับ `acd`

ตารางมี $(n + 1)(m + 1)$ ช่อง ช่องละ $O(1)$ รวม $O(nm)$ ทั้งเวลาและหน่วยความจำ ถ้าต้องการแค่ความยาว แถว $i$ ใช้แค่แถว $i - 1$ จึงเก็บสองแถวพอ เหลือหน่วยความจำ $O(m)$ (แต่ย้อนรอยไม่ได้แล้ว)

### Edit distance

โจทย์ตระกูลเดียวกันที่เจอบ่อยมากคือ **edit distance**: แก้ $A$ ให้เป็น $B$ ด้วยการแทรก, ลบ หรือเปลี่ยนตัวอักษรทีละตัว ใช้น้อยครั้งที่สุดเท่าไร state ก็เป็น prefix เหมือนเดิม `dp[i][j]` = ต้นทุนน้อยสุดในการแก้ $A$ ตัวแรก $i$ ตัว ให้เป็น $B$ ตัวแรก $j$ ตัว แล้วถามว่า **การแก้ครั้งสุดท้าย** ทำอะไรกับตัวท้าย ซึ่งก็คือสามลูกศรในรูปข้างบนนั่นเอง ต่างกันแค่ว่าแต่ละลูกศรมีต้นทุนเท่าไร และ base case ไม่ใช่ $0$ อีกต่อไป (แก้ prefix ยาว $i$ ให้เป็นสตริงว่าง ต้องทำอะไรกี่ครั้ง?)

:::problem lp_dpk02_typo_fixer

:::hint ใบ้ Typo Fixer
จับคู่สามลูกศรกับสามการแก้: ลูกศรไหนคือ "ลบ `A[i-1]` ทิ้ง", ลูกศรไหนคือ "แทรก `B[j-1]` ต่อท้าย" และลูกศรทิแยงคือ "ทำให้ `A[i-1]` กลายเป็น `B[j-1]`" ซึ่งไม่เสียอะไรถ้าสองตัวเท่ากันอยู่แล้ว แล้วเอาค่าน้อยสุดของสามทาง ระวัง base case `dp[i][0]` กับ `dp[0][j]` และใน Python ให้เก็บแค่สองแถว พร้อมเลี่ยงการเรียกฟังก์ชันในลูปใน
:::

## 0/1 knapsack

ของ $n$ ชิ้น ชิ้นที่ $i$ หนัก $w_i$ มีค่า $v_i$ กระเป๋ารับได้ไม่เกิน $W$ แต่ละชิ้น **เอาหรือไม่เอา** (เอาซ้ำไม่ได้ เลยเรียกว่า 0/1) ได้ค่ามากสุดเท่าไร

ลองทุกชุดคือ $2^n$ ซึ่งไม่ไหว แต่ถ้า $W$ ไม่ใหญ่มาก DP ช่วยได้

* State: `dp[i][c]` = ค่ามากสุดเมื่อพิจารณาของ $i$ ชิ้นแรก โดยน้ำหนักรวมไม่เกิน $c$
* Transition: ชิ้นที่ $i$ (ดัชนี $i - 1$) ไม่เอา: `dp[i-1][c]` หรือเอา (ถ้า $w \leq c$): `dp[i-1][c-w] + v`
* Base case: `dp[0][c] = 0` ทุก $c$ ไม่มีของก็ไม่มีค่า

ตาราง $(n + 1) \times (W + 1)$ ใช้ได้ แต่สังเกตว่าแถว $i$ ใช้แค่แถว $i - 1$ จึงเหลืออาเรย์ **เดียว** ได้ โดย **วน $c$ จากมากไปน้อย**

### ทำไมต้องวนถอยหลัง

ตอนอัปเดต `dp[c]` เราต้องการ `dp[c - w]` ของ **แถวก่อนหน้า** (ยังไม่ได้ใส่ชิ้นนี้) ถ้าวน $c$ จากน้อยไปมาก `dp[c - w]` ถูกอัปเดตไปก่อนแล้วในรอบนี้ แปลว่ามันอาจ **ใส่ชิ้นนี้ไปแล้ว** แล้วเราก็ใส่ซ้ำอีก

```text
ของชิ้นเดียว w = 3, v = 4, W = 7       เริ่ม dp = [0 0 0 0 0 0 0 0]

วนขึ้น (ผิด):  c=3: dp[3] = dp[0]+4 = 4
               c=6: dp[6] = dp[3]+4 = 8     <- dp[3] มีชิ้นนี้อยู่แล้ว ใส่ซ้ำสองชิ้น!
วนลง (ถูก):    c=6: dp[6] = dp[3]+4 = 4     <- dp[3] ยังเป็นของแถวก่อน (0)
               c=3: dp[3] = dp[0]+4 = 4
```

วนถอยหลังทำให้ทุกช่องที่อ่าน ($c - w < c$) ยังไม่ถูกแตะในรอบนี้ จึงเป็นค่าของแถวก่อนหน้าพอดี

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  int n, cap;
  cin >> n >> cap;
  vector<long long> dp(cap + 1, 0);       // dp[c] = ค่ามากสุด น้ำหนักรวมไม่เกิน c
  for (int i = 0; i < n; i++) {
    int w;
    long long v;
    cin >> w >> v;
    for (int c = cap; c >= w; c--)         // ถอยหลัง: ใช้แต่ละชิ้นได้ครั้งเดียว
      dp[c] = max(dp[c], dp[c - w] + v);
  }
  cout << dp[cap] << '\n';
}
```

ไล่มือกับ $W = 7$ และของ $(w, v) = (3, 4), (4, 5), (2, 3)$

| หลังใส่ชิ้น | $c = 0$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| (เริ่ม) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| $(3, 4)$ | 0 | 0 | 0 | 4 | 4 | 4 | 4 | 4 |
| $(4, 5)$ | 0 | 0 | 0 | 4 | 5 | 5 | 5 | 9 |
| $(2, 3)$ | 0 | 0 | 3 | 4 | 5 | 7 | 8 | 9 |

ตอบ `dp[7] = 9` คือเอาชิ้นแรกกับชิ้นที่สอง (หนัก $7$ พอดี) ช่อง `dp[6] = 8` มาจาก `dp[4] + 3` คือชิ้นที่สองกับชิ้นที่สาม

เวลา $O(nW)$ หน่วยความจำ $O(W)$ ซึ่ง **ขึ้นกับขนาดของ $W$** ไม่ใช่จำนวนหลักของมัน $W = 10^5$ สบาย ๆ แต่ $W = 10^9$ สร้างอาเรย์ไม่ได้แล้ว

### Unbounded knapsack

ถ้าแต่ละชนิดเอากี่ชิ้นก็ได้ บั๊กของการวนขึ้นข้างบนกลายเป็นสิ่งที่เราต้องการพอดี: วน $c$ **จากน้อยไปมาก** แล้ว `dp[c - w]` ที่อาจมีชิ้นนี้อยู่แล้วก็ใส่เพิ่มได้อีก แก้บรรทัดเดียว

```cpp
for (int c = w; c <= cap; c++)             // ไปข้างหน้า: ใช้ชิ้นเดิมซ้ำได้
  dp[c] = max(dp[c], dp[c - w] + v);
```

นี่คือโครงเดียวกับ coin change แบบไม่สนลำดับในบทที่แล้ว (ลูปเหรียญอยู่ข้างนอก วนเงินขึ้น)

### ย้อนหาว่าเลือกชิ้นไหน

อาเรย์เดียวให้แค่ค่าที่ดีที่สุด ถ้าโจทย์อยากรู้ **ว่าเลือกชิ้นไหน** ให้เก็บตารางสองมิติเต็ม ๆ แล้วย้อนจาก $(n, W)$: ถ้า `dp[i][c] != dp[i-1][c]` แปลว่าชิ้นที่ $i$ ถูกเลือกแน่นอน (ไม่เลือกค่าจะเท่ากับแถวบน) ให้ลด $c$ ลง $w_i$ แล้วขึ้นแถว

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  int n, cap;
  cin >> n >> cap;
  vector<int> w(n + 1);
  vector<long long> v(n + 1);
  for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];
  vector<vector<long long>> dp(n + 1, vector<long long>(cap + 1, 0));
  for (int i = 1; i <= n; i++)
    for (int c = 0; c <= cap; c++) {
      dp[i][c] = dp[i - 1][c];                                   // ไม่เอาชิ้น i
      if (w[i] <= c) dp[i][c] = max(dp[i][c], dp[i - 1][c - w[i]] + v[i]);
    }

  vector<int> chosen;
  for (int i = n, c = cap; i >= 1; i--)
    if (dp[i][c] != dp[i - 1][c]) {   // ค่าเปลี่ยน = ชิ้น i ถูกเลือก
      chosen.push_back(i);
      c -= w[i];
    }
  reverse(chosen.begin(), chosen.end());
  cout << dp[n][cap] << '\n';
  for (int i : chosen) cout << i << ' ';
  cout << '\n';
}
```

กับตัวอย่างเดิม (`3 7` แล้วของสามชิ้น) โปรแกรมพิมพ์ `9` และ `1 2` ตารางสองมิติใช้หน่วยความจำ $O(nW)$ ถ้า $n = 100$ และ $W = 10^5$ ก็ $10^7$ ช่อง `long long` คือ $80$ MB ยังพอไหว แต่ควรคำนวณก่อนทุกครั้ง

:::problem lp_dpk03_heavy_treasures

:::hint ใบ้ Heavy Treasures
$W$ ถึง $10^9$ จึงสร้าง `dp[c]` ไม่ได้ แต่มูลค่ารวมทั้งหมดมีแค่ไม่เกิน $100 \times 1{,}000 = 10^5$ ลอง **สลับบทบาท** ของน้ำหนักกับมูลค่าใน state ดู: แทนที่จะถาม "น้ำหนักไม่เกิน $c$ ได้มูลค่ามากสุดเท่าไร" ให้ถาม "อยากได้มูลค่ารวม $s$ พอดี ต้องหนักน้อยสุดเท่าไร" แล้วคำตอบคือ $s$ ที่มากที่สุดที่น้ำหนักนั้นไม่เกิน $W$ ยังเป็น 0/1 อยู่ ทิศของลูปจึงสำคัญเหมือนเดิม และน้ำหนักรวมเกิน `int` ได้
:::

## ความซับซ้อน

| โจทย์ | state | งานต่อ state | เวลา | หน่วยความจำ (แบบประหยัด) |
|---|---|---|---|---|
| เส้นทางในตาราง | $RC$ | $O(1)$ | $O(RC)$ | $O(C)$ |
| LCS / edit distance | $nm$ | $O(1)$ | $O(nm)$ | $O(m)$ |
| 0/1 และ unbounded knapsack | $nW$ | $O(1)$ | $O(nW)$ | $O(W)$ |

ก่อนเขียนให้คูณขนาดจริงดูเสมอ ถ้าได้ประมาณ $10^8$ ใน C++ ยังพอไหว แต่ใน Python ควรอยู่ราว $10^6$ ถึง $10^7$ ซึ่งก็ต้องเขียนลูปในให้เรียบที่สุดด้วย

## จุดที่พลาดบ่อย

:::warning ทิศของลูป knapsack
0/1 ต้อง **ถอยหลัง** unbounded ต้อง **ไปข้างหน้า** สลับกันเมื่อไรได้คำตอบผิดแบบเงียบ ๆ (ตัวอย่างบนกระดาษมักยังถูก) ถ้าไม่แน่ใจ ลองใส่ของชิ้นเดียวแล้วดูว่า `dp` ใส่มันซ้ำหรือเปล่า
:::

:::warning "ไปไม่ถึง" ไม่เท่ากับ $0$
ในตารางเส้นทางหรือ knapsack แบบ "พอดี" ช่องที่เป็นไปไม่ได้ต้องมีค่าพิเศษ (INF หรือ $-1$) แยกจากช่องที่ได้ค่า $0$ จริง ๆ ถ้าใช้ $0$ แทนทั้งคู่ จะเผลอต่อเส้นทางจากช่องที่ไปไม่ถึง
:::

:::warning ดัชนี prefix เลื่อนหนึ่ง
`dp[i][j]` คือ prefix ยาว $i$ กับ $j$ ตัวท้ายจึงเป็น `A[i-1]` กับ `B[j-1]` ไม่ใช่ `A[i]` ตารางขนาด $(n + 1) \times (m + 1)$ แถว $0$ กับคอลัมน์ $0$ คือ prefix ว่าง
:::

:::warning ตาราง 2D ใหญ่เกินหน่วยความจำ
$5{,}000 \times 5{,}000$ ช่อง `int` คือ $100$ MB ถ้าแต่ละแถวใช้แค่แถวก่อนหน้า ให้เก็บสองแถวแล้วสลับกัน เว้นแต่ต้องย้อนรอยหาคำตอบ
:::

## สรุปสั้น ๆ

* state สองมิติยังใช้สี่คำถามเดิม แต่ลำดับการเติมต้องให้ทุกช่องที่ต้องใช้ถูกเติมไว้ก่อน (ตาราง: บนลงล่าง ซ้ายไปขวา)
* เส้นทางขวา/ลง: มาจากบนหรือซ้าย นับวิธีใช้บวก ค่าดีสุดใช้ min/max และแยก "ไปไม่ถึง" ออกจาก $0$
* สองสตริง: state เป็น prefix ทั้งคู่ แล้วดูตัวท้าย (ทิแยง / บน / ซ้าย) ได้ทั้ง LCS และ edit distance
* 0/1 knapsack อาเรย์เดียววน $c$ ถอยหลัง, unbounded วนไปข้างหน้า, เวลา $O(nW)$
* อยากรู้ว่าเลือกอะไร เก็บตารางเต็มแล้วย้อนรอยจากช่องคำตอบ
* ถ้ามิติไหนใหญ่เกิน ลองสลับว่าอะไรเป็น state อะไรเป็นค่าที่เก็บ
