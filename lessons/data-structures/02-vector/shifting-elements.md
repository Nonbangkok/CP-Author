## ทำไมต้องเลื่อน

ใน `CP::vector` สมาชิกต้องเรียงติดกันตั้งแต่ดัชนี `0` ถึง `mSize - 1` ห้ามมีรู ดังนั้นการลบหรือแทรกตรงกลางจึงต้อง **เลื่อน** ข้อมูลส่วนที่เหลือเพื่ออุดรูหรือเปิดช่องว่าง และนี่คือที่มาของเวลา $O(n)$

## ลบ: เลื่อนจากซ้ายไปขวา

ถ้าจะลบดัชนี `pos` ก็ให้ทุกตัวที่อยู่ทางขวาขยับมาทางซ้ายหนึ่งช่อง แล้วลด `mSize`

```text
ก่อน:  [ A  B  C  D  E ]     ลบ pos = 1 (ตัว B)
เลื่อน: [ A  C  D  E  E ]     C, D, E ขยับมาซ้ายทีละตัว
หลัง:  [ A  C  D  E ]        mSize ลดจาก 5 เป็น 4
```

ลูปต้องเดิน **จากซ้ายไปขวา** คือ `mData[pos] = mData[pos + 1]` ก่อน แล้วค่อยไปตัวถัดไป ถ้าเดินกลับทิศจะไปเขียนทับค่าที่ยังไม่ได้ย้าย เวลาที่ใช้คือ $O(\text{mSize} - \text{pos})$ ลบตัวท้ายเลยเร็ว แต่ลบตัวแรกช้าที่สุด

:::problem hp_vec04_erase

## แทรก: ขอที่ก่อน แล้วเลื่อนจากขวาไปซ้าย

การแทรกค่า `x` ที่ `pos` กลับด้านกับการลบ

1. `ensureCapacity(mSize + 1)` ให้มีที่สำหรับตัวเพิ่ม
2. เลื่อนทุกตัวตั้งแต่ `pos` ไปทางขวาหนึ่งช่อง โดยเดิน **จากขวาไปซ้าย** เริ่มจากตัวท้ายสุด
3. ใส่ `x` ที่ `mData[pos]` แล้วเพิ่ม `mSize`

:::warning ระวัง size_t ตอนนับถอยหลัง
`size_t` ไม่มีค่าติดลบ ถ้าเขียน `for (size_t i = mSize - 1; i >= pos; i--)` แล้ว `pos` เป็น `0` เงื่อนไข `i >= 0` จะจริงตลอดกาล เพราะ `0 - 1` วนกลับไปเป็นเลขที่ใหญ่มาก ลูปเลยไม่จบ แก้ได้ด้วยการวนแบบ `for (size_t i = mSize; i > pos; i--) mData[i] = mData[i - 1];` แทน
:::

### กับดักที่เจ็บที่สุด

ถ้ามีคนเรียก `v.insert(0, v[3])` ค่า `x` ที่ส่งเข้ามาเป็น `const T &` ที่ชี้ไปที่ `mData[3]` ของ vector ตัวเดียวกัน ทีนี้ถ้า `ensureCapacity` ไปเรียก `expand` อาเรย์เก่าจะถูก `delete[]` ทิ้ง แล้ว `x` ก็กลายเป็น reference ที่ชี้ไปที่หน่วยความจำที่คืนไปแล้ว

วิธีกันง่าย ๆ คือ **copy ค่าไว้ก่อน** เช่น `T value = x;` ที่บรรทัดแรกของฟังก์ชัน แล้วใช้ `value` แทน `x` จากนั้นเป็นต้นไป

## ลบหลายตัวในรอบเดียว

สมมติต้องลบ $k$ ตำแหน่งจาก vector ขนาด $n$ ถ้าเรียกการลบทีละตัว $k$ ครั้ง จะใช้เวลา $O(nk)$ ซึ่งถ้า $n$ และ $k$ ใหญ่ทั้งคู่ ก็ TLE แน่นอน

ท่าที่ใช้แทนคือ **สองพอยน์เตอร์** ตัวหนึ่ง (`r`) อ่านทุกตัวจากซ้ายไปขวา อีกตัว (`w`) ชี้ช่องถัดไปที่จะเขียน ตัวไหนเก็บไว้ก็เขียนลงที่ `w` แล้วเลื่อน `w` ตัวไหนจะทิ้งก็แค่ข้ามไป ตัวอย่างข้างล่างลบทุกตัวที่เท่ากับ `bad` ซึ่งเป็นโจทย์คนละข้อกับในแบบฝึก แต่ใช้ท่าเดียวกัน

```cpp
size_t w = 0;
for (size_t r = 0; r < mSize; r++)
{
  if (!(mData[r] == bad))
    mData[w++] = mData[r];
}
mSize = w;
```

ทุกตัวถูกอ่านครั้งเดียวและเขียนไม่เกินครั้งเดียว รวมแล้วจึงเป็น $O(n)$ ไม่ว่าจะลบกี่ตัวก็ตาม

:::problem hp_vec06_erase_many

:::hint ใบ้ Erase Many
ตำแหน่งที่ต้องลบมาเรียงจากน้อยไปมากอยู่แล้ว ระหว่างที่ `r` เดินไป ให้มีอีกตัวชี้ว่า "ตำแหน่งที่ต้องลบตัวถัดไปคือตัวไหน" ถ้า `r` ตรงกับตำแหน่งนั้นก็ข้ามแล้วขยับตัวชี้ ถ้าไม่ตรงก็เขียนลงที่ `w`
:::

## แทรกเป็นก้อน

ถ้าต้องแทรก $m$ ตัวที่ตำแหน่งเดียวกัน อย่าเรียกแทรกทีละตัว $m$ ครั้ง ให้คิดแบบก้อนเดียวแทน: `ensureCapacity(mSize + m)` ครั้งเดียว แล้วเลื่อนส่วนท้ายไปทางขวาทีเดียว $m$ ช่อง จากนั้นค่อยเติมของใหม่ลงในช่องว่าง เวลารวมจะเหลือ $O(n + m)$

## หมุนอาเรย์โดยไม่ใช้อาเรย์ช่วย

ข้อท้าทายของบทนี้คือหมุนซ้ายไป $k$ ช่องในเวลา $O(n)$ โดยใช้หน่วยความจำเพิ่มแค่ $O(1)$ การ copy ไปไว้ในอาเรย์ชั่วคราวจะเกินหน่วยความจำ

:::hint ใบ้ Vector Rotate
ลองกลับด้านสามครั้งดู: กลับ `[0, k)` กลับ `[k, n)` แล้วกลับทั้งอาเรย์ ลองทำกับ `A B C D E` ที่ $k = 2$ บนกระดาษ แล้วจะเห็นเองว่ามันได้ `C D E A B` และอย่าลืมว่า $k$ อาจใหญ่กว่า $n$ ได้ ให้ใช้ $k \bmod n$ (และระวังตอน $n = 0$)
:::

## สรุปสั้น ๆ

* ลบ: เลื่อนซ้าย เดินจากซ้ายไปขวา ส่วนแทรก: ขอที่ก่อน แล้วเลื่อนขวาโดยเดินจากขวาไปซ้าย
* นับถอยหลังด้วย `size_t` ให้ใช้ `i > pos` ไม่ใช่ `i >= pos`
* ค่าที่รับมาเป็น reference ให้ copy ไว้ก่อนเรียก `ensureCapacity`
* งานหลายตำแหน่งพร้อมกันให้ทำในรอบเดียว ด้วยสองพอยน์เตอร์หรือการเลื่อนทั้งก้อน
