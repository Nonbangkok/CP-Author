## header-problems

50 header problems (`student.h`) for Grader OJ — pair, vector, stack, queue, priority_queue — with statements, reference solutions, graders, generators and the build harness that produces the import ZIP. See [header-problems/README.md](header-problems/README.md).

## lessons

Lessons for Grader OJ's Learn section (`/learn`) — tracks of short Thai lessons that end in problems the grader already has, packed into one import ZIP by `./run.sh build`. The first track, *Data Structures (CP::)*, teaches the five classes behind the header problems. See [lessons/README.md](lessons/README.md).

## standard-problems

Stdin/stdout practice problems for the Learn lessons (C++ and Python), with a harness that reuses the header-problem image to render the statement, build testcases from the reference, and prove the promised complexity with a `slow.cpp`. See [standard-problems/README.md](standard-problems/README.md).
